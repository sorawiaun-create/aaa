# Profit Desk — แดชบอร์ดกำไร/ขาดทุน & กระทบยอด Shopee / TikTok

ระบบบัญชีกำไร-ขาดทุนและกระทบยอดรายรับ–รายจ่ายสำหรับร้านค้าออนไลน์บน **Shopee** และ **TikTok Shop**
ทำงานทั้งหมดในเบราว์เซอร์ (ข้อมูลเก็บใน `localStorage` ของเครื่องคุณ ไม่ส่งขึ้นเซิร์ฟเวอร์)

## แนวคิดหลัก

ไฟล์ยอดขายจากแพลตฟอร์ม **ไม่มีต้นทุนสินค้า** — ระบบจึงให้คุณกำหนดต้นทุนต่อหน่วยตาม **SKU** เอง
แล้วจับคู่กับยอดขายเพื่อคำนวณกำไรอัตโนมัติ:

```
กำไรขั้นต้น (Gross Profit) = รายได้ − ต้นทุนสินค้า (COGS)
กำไรสุทธิ  (Net Profit)   = กำไรขั้นต้น − ค่าธรรมเนียม/โฆษณา (รวม VAT)
```

> ภาษีหัก ณ ที่จ่าย (WHT) แสดงแยกต่างหากในฐานะเครดิตภาษี ไม่ถูกหักออกจากกำไร

## การเชื่อมไฟล์ (สำคัญ)

- **Shopee ใช้ไฟล์เดียวจบ** — ไฟล์ออเดอร์มี SKU + ยอดขาย + ค่าธรรมเนียมรายบรรทัด (คอมมิชชั่น/ธุรกรรม/บริการ) ครบในตัว
- **TikTok ใช้ 2 ไฟล์** — ไฟล์ออเดอร์ (SKU + ยอดขาย) + ไฟล์ settlement (ค่าธรรมเนียม) เชื่อมกันด้วย **หมายเลขคำสั่งซื้อ (Order ID)** เพราะไฟล์ค่าธรรมเนียมไม่มี SKU
- ระบบเลือกแหล่งค่าธรรมเนียมให้อัตโนมัติต่อแพลตฟอร์ม (ไม่นับซ้ำ) และเฉลี่ยค่าธรรมเนียมระดับออเดอร์ลงราย SKU ตามสัดส่วนยอดขาย

## ฟีเจอร์

- **แดชบอร์ด P&L** — รายได้ / ต้นทุน / กำไรขั้นต้น / ค่าธรรมเนียม / กำไรสุทธิ / margin, กราฟรายเดือน, โครงสร้างค่าใช้จ่าย, สรุปแยกแพลตฟอร์ม, กระทบยอดจาก settlement, **สินค้าขายดี Top 10**, **สรุปรายเดือน + การเติบโต MoM**
- **กำไรจริง (รายออเดอร์)** — เชื่อมออเดอร์กับค่าธรรมเนียมด้วย Order ID → กำไรสุทธิรายออเดอร์, สถานะจับคู่/รอ settlement, ส่งออก CSV
- **กำไรราย SKU** — กำไรขั้นต้น/สุทธิราย SKU, จัดอันดับ, แก้ต้นทุนในตารางได้ทันที, ส่งออก CSV
- **วิเคราะห์สินค้า** — สินค้าขายดี (กราฟแท่ง), แนวโน้มรายสินค้าต่อเดือน, **เปรียบเทียบหลายสินค้าในกราฟเดียว**, **สัดส่วนตามหมวดหมู่**, ตาราง pivot สินค้า × เดือน, ส่งออก CSV
- **สลับภาษา ไทย / อังกฤษ (TH/EN)** — ปุ่มสลับภาษาที่แถบเมนู (จำค่าไว้ในเบราว์เซอร์)
- **สินค้า & ต้นทุน** — ทะเบียน SKU + ต้นทุนต่อหน่วย, นำเข้าต้นทุนจาก CSV, เตือน SKU ที่ขายแต่ยังไม่ตั้งต้นทุน
- **นำเข้ายอดขาย** — รองรับ CSV / Excel ทุกแพลตฟอร์ม พร้อม **จับคอลัมน์อัตโนมัติ** และแมปเองได้ (auto-detect + preview)
- **นำเข้าค่าธรรมเนียม** — ไฟล์ settlement Excel (รายรับ Shopee / รายงาน TikTok) และใบเสร็จ PDF ดึงค่าธรรมเนียมทั้งเดือน + รายออเดอร์ + VAT + WHT
- **ตัวกรอง** — แพลตฟอร์ม, ช่วงเดือน, สถานะออเดอร์ (เช่น นับเฉพาะออเดอร์สำเร็จ)
- **จัดการข้อมูล** — สำรอง/กู้คืน (JSON), โหลดข้อมูลตัวอย่าง, ล้างข้อมูล

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
```

คำสั่งอื่น:

```bash
npm run build    # สร้างไฟล์ production ในโฟลเดอร์ dist/
npm run preview  # พรีวิว build
npm test         # รันชุดทดสอบตรรกะการคำนวณ (node:test)
```

## Deploy ออนไลน์ (ฟรี)

แอปเป็นเว็บ static (ข้อมูลอยู่ใน browser) จึง deploy ฟรีได้ทันที มีไฟล์ config ให้แล้ว
(`vercel.json`, `netlify.toml`)

**Vercel:** ล็อกอิน vercel.com ด้วย GitHub → Add New → Project → เลือก repo นี้ →
เลือก branch → Deploy (ตรวจว่า Framework = Vite, Build = `npm run build`, Output = `dist`)

**Netlify:** ล็อกอิน netlify.com ด้วย GitHub → Add new site → Import an existing project →
เลือก repo/branch → ค่าถูกตั้งไว้ใน `netlify.toml` แล้ว → Deploy

**Cloudflare Pages:** Create application → Pages → Connect to Git → Build command `npm run build`,
Output `dist`

จะได้ลิงก์เว็บถาวรเปิดใช้จากมือถือ/ที่ไหนก็ได้ และทุกครั้งที่ push โค้ดใหม่ ระบบจะ deploy ให้อัตโนมัติ

## ขั้นตอนใช้งานแนะนำ

1. ไปที่ **จัดการข้อมูล → โหลดข้อมูลตัวอย่าง** เพื่อดูภาพรวม (หรือข้ามไปใช้ไฟล์จริง)
2. **นำเข้ายอดขาย** อัปโหลดไฟล์ของแต่ละแพลตฟอร์ม ตรวจการจับคู่คอลัมน์แล้วยืนยัน
3. **สินค้า & ต้นทุน** กรอกต้นทุนต่อหน่วยของแต่ละ SKU (หรือ นำเข้าจาก CSV)
4. **นำเข้าค่าธรรมเนียม** อัปโหลดใบเสร็จ PDF
5. ดูผลที่ **แดชบอร์ด** และ **กระทบยอด / กำไร**

```

    salesParser.js     # อ่าน CSV/XLSX + จับคอลัมน์อัตโนมัติ
    pdfParser.js       # ดึงค่าธรรมเนียมจากใบเสร็จ PDF
    reconcile.js       # เอนจินคำนวณกำไร/ขาดทุน (P&L)
    store.js           # state + persistence (localStorage)
    sampleData.js      # ชุดข้อมูลตัวอย่าง
  views/               # หน้าจอแต่ละส่วน
test/logic.test.js     # ทดสอบตรรกะการคำนวณ
```
