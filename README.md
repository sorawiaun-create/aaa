# ระบบ AI ผลิตคอนเทนต์แบบหลายแผนก (ฉบับเต็ม) 🎬

ระบบ AI ที่ทำงานอัตโนมัติแบบ **"เอเจนซี่ทั้งทีม"** — แบ่งเป็นหลายแผนก แต่ละแผนกดูแลคนละส่วน
โดยมี **"ผู้จัดการ" (AI)** คอยแตกงานและสั่งงานแต่ละแผนกเองอัตโนมัติ **และสร้างไฟล์ผลงานจริง**
(ภาพ, บรีฟวิดีโอ, ไฟล์โพสต์แยกแพลตฟอร์ม) พร้อม **หน้าพรีวิว HTML** รวมงานทั้งแคมเปญ

> รับโจทย์เดียว เช่น *"ทำแคมเปญเปิดตัวสินค้าใหม่ ลง TikTok/IG/FB"* →
> ระบบวางแผน สั่งงานทุกแผนก สร้างไฟล์งาน แล้วรวมเป็น **แพ็กเกจคอนเทนต์พร้อมเผยแพร่**

## แผนกในระบบ (8 แผนก)

1. 🧭 **วางแผนกลยุทธ์คอนเทนต์** — แปลงโจทย์เป็นแผน + รายการชิ้นงาน
2. 🔥 **วิจัยเทรนด์ & แฮชแท็ก** — มุมมาแรง + แฮชแท็ก/คีย์เวิร์ด
3. ✍️ **เขียนบท & แคปชั่น** — hook, สคริปต์, แคปชั่น, CTA
4. 🎥 **วิดีโอ** — สตอรี่บอร์ด + *สร้างไฟล์บรีฟวิดีโอจริง* (ต่อ text-to-video ได้)
5. 🎨 **ภาพ & กราฟิก** — ทิศทางภาพ + *สร้างไฟล์ภาพจริง* (ต่อ text-to-image ได้)
6. 🤝 **ประสานอินฟลูเอนเซอร์** — เลือก KOL + ร่างบรีฟ + วิธีวัดผล
7. 📢 **ยิงแอด (Paid Media)** — โครงสร้างแคมเปญ + ad copy + ตัวชี้วัด
8. 📱 **จัดโพสต์ตามแพลตฟอร์ม** — ปรับคอนเทนต์แต่ละแพลตฟอร์ม + *บันทึกไฟล์โพสต์จริง*
9. ✅ **ตรวจแบรนด์ & คุณภาพ** — ตรวจก่อนปล่อย

> เพิ่มแผนกใหม่ได้ง่ายมาก — แค่เพิ่ม object ใน `src/departments/index.js` ระบบสร้าง tool ให้ผู้จัดการอัตโนมัติ

ดูรายละเอียดสถาปัตยกรรมได้ที่ [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## วิธีใช้งาน

```bash
# 1. ติดตั้ง dependency
npm install

# 2. ตั้งค่า API key (เลือกอย่างใดอย่างหนึ่ง)
export ANTHROPIC_API_KEY=sk-ant-xxxx
#   หรือ คัดลอก .env.example เป็น .env แล้วใส่ค่า

# 3. รันด้วยโจทย์ของคุณ
node src/index.js "ทำคอนเทนต์เปิดตัวร้านกาแฟใหม่ ลง TikTok และ Instagram โทนอบอุ่น"

# หรือรันตัวอย่างสำเร็จรูป
npm run demo
```

### ผลลัพธ์ที่ได้

ระบบจะสร้างโฟลเดอร์ `output/<ชื่อแคมเปญ>-<เวลา>/` ที่มี:

```
output/<campaign>/
├── index.html              ← หน้าพรีวิวรวมงานทั้งหมด (เปิดในเบราว์เซอร์)
├── 01-strategy.md          ← ผลงานแต่ละแผนก (เรียงตามลำดับที่ทำ)
├── 02-trend.md
├── ...
├── post-tiktok.md          ← ไฟล์โพสต์แยกแพลตฟอร์ม (ก็อปไปตั้งเวลาโพสต์ได้)
├── post-instagram.md
├── 99-final-summary.md     ← สรุปจากผู้จัดการ
└── assets/                 ← ไฟล์ภาพ (SVG/รูป) และบรีฟวิดีโอ
```

## โครงสร้างโปรเจกต์

```
src/
├── index.js              # จุดเริ่มต้น (CLI) + โหลด .env + สร้างพรีวิว
├── config.js             # ตั้งค่าโมเดล / effort / provider สื่อ
├── orchestrator.js       # "ผู้จัดการ" — แตกงาน สั่งงาน รวบรวม (agentic loop + tool use)
├── output.js             # เลเยอร์บันทึกไฟล์ + สร้างหน้าพรีวิว HTML
├── util.js               # ฟังก์ชันช่วย (slug, escape, ฯลฯ)
├── providers/
│   └── media.js          # เลเยอร์ผลิตสื่อ (ภาพ/วิดีโอ) — placeholder + จุดต่อ API จริง
└── departments/
    └── index.js          # นิยามทุกแผนก (หน้าที่ + system prompt + tools)
docs/
└── ARCHITECTURE.md       # แผนผังและรายละเอียดระบบ
```

## ต่อ API สร้างภาพ/วิดีโอจริง
