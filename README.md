# ระบบ AI ผลิตคอนเทนต์แบบหลายแผนก (ฉบับเต็ม) 🎬

ระบบ AI ที่ทำงานอัตโนมัติแบบ **"เอเจนซี่ทั้งทีม"** — แบ่งเป็นหลายแผนก แต่ละแผนกดูแลคนละส่วน
โดยมี **"ผู้จัดการ" (AI)** คอยแตกงานและสั่งงานแต่ละแผนกเองอัตโนมัติ **และสร้างไฟล์ผลงานจริง**
(ภาพ, บรีฟวิดีโอ, ไฟล์โพสต์แยกแพลตฟอร์ม) พร้อม **หน้าพรีวิว HTML** รวมงานทั้งแคมเปญ

> รับโจทย์เดียว เช่น *"ทำแคมเปญเปิดตัวสินค้าใหม่ ลง TikTok/IG/FB"* →
> ระบบวางแผน สั่งงานทุกแผนก สร้างไฟล์งาน แล้วรวมเป็น **แพ็กเกจคอนเทนต์พร้อมเผยแพร่**

## แผนกในระบบ (8 แผนก)

1. 🧭 **วางแผนกลยุทธ์คอนเทนต์** — แปลงโจทย์เป็นแผน + รายการชิ้นงาน
2. 🔥 **วิจัยเทรนด์ & แฮชแท็ก** — มุมมาแรง + แฮชแท็ก/คีย์เวิร์ด
3. ✍️ **เขียนบท & แคปชั่น** — hook, สคริปต์, แคปชั่น, CTA
4. 🎥 **วิดีโอ** — สตอรี่บอร์ด + *สร้างไฟล์บรีฟวิดีโอจริง* (ต่อ text-to-video ได้)
5. 🎨 **ภาพ & กราฟิก** — ทิศทางภาพ + *สร้างไฟล์ภาพจริง* (ต่อ text-to-image ได้)
6. 🤝 **ประสานอินฟลูเอนเซอร์** — เลือก KOL + ร่างบรีฟ + วิธีวัดผล
7. 📢 **ยิงแอด (Paid Media)** — โครงสร้างแคมเปญ + ad copy + ตัวชี้วัด
8. 📱 **จัดโพสต์ตามแพลตฟอร์ม** — ปรับคอนเทนต์แต่ละแพลตฟอร์ม + *บันทึกไฟล์โพสต์จริง*
9. ✅ **ตรวจแบรนด์ & คุณภาพ** — ตรวจก่อนปล่อย

> เพิ่มแผนกใหม่ได้ง่ายมาก — แค่เพิ่ม object ใน `src/departments/index.js` ระบบสร้าง tool ให้ผู้จัดการอัตโนมัติ

ดูรายละเอียดสถาปัตยกรรมได้ที่ [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## วิธีใช้งาน — ผ่านเว็บ ครบจบในที่เดียว 🖥️ (แนะนำ)

```bash
npm install
npm run web        # เปิด http://localhost:4321
```

เปิดเบราว์เซอร์แล้วใช้งานได้เลย ไม่ต้องพิมพ์คำสั่ง:

- **หน้า 🎬 ผลิตคอนเทนต์ (Studio)** — พิมพ์โจทย์ → กด **ผลิตคอนเทนต์** → เห็น **ห้องแต่ละแผนกทำงานสดๆ** (ไฟเขียว+การ์ตูนวิ่ง) → เปิดแดชบอร์ดแคมเปญ → กด **เผยแพร่** ขึ้นทุกแพลตฟอร์ม
- **หน้า ⚙️ ตั้งค่า API** — กรอก key ของแต่ละ AI และแต่ละแพลตฟอร์มลงช่อง กดบันทึก (เซฟลง `.env` อัตโนมัติ มีผลทันที)

> **ยังไม่ใส่ Anthropic key ก็กดลองได้** — ระบบจะรัน **โหมดสาธิต** (ใช้ภาพตัวอย่าง) ให้เห็นการทำงานทั้งหมด
> พอใส่ key จริงในหน้าตั้งค่า ก็ผลิตด้วย AI จริงทันที

### หรือใช้ผ่าน command line

```bash
node src/index.js "ทำคอนเทนต์เปิดตัวร้านกาแฟใหม่ ลง TikTok และ Instagram โทนอบอุ่น"
node src/publish.js "output/<แคมเปญ>"
```

### ผลลัพธ์ที่ได้

ระบบจะสร้างโฟลเดอร์ `output/<ชื่อแคมเปญ>-<เวลา>/` ที่มี:

```
output/<campaign>/
├── index.html              ← 🎮 แดชบอร์ด "ศูนย์บัญชาการ AI" (เปิดในเบราว์เซอร์)
│                              แต่ละแผนก = 1 ห้อง มีไฟเขียว+ตัวการ์ตูนวิ่งทำงาน
│                              เล่น replay ตามลำดับที่ทำจริง · คลิกห้องดูผลงาน+ภาพ+โพสต์
├── 01-strategy.md          ← ผลงานแต่ละแผนก (เรียงตามลำดับที่ทำ)
├── 02-trend.md
├── ...
├── post-tiktok.md          ← ไฟล์โพสต์แยกแพลตฟอร์ม (ก็อปไปตั้งเวลาโพสต์ได้)
├── post-instagram.md
├── 99-final-summary.md     ← สรุปจากผู้จัดการ
└── assets/                 ← ไฟล์ภาพ (SVG/รูป) และบรีฟวิดีโอ
```


## เปิดโหมดเจนภาพ/วิดีโอจริง 🖼️🎥

ค่าเริ่มต้นใช้โหมด `placeholder` (สร้างไฟล์ตัวอย่าง SVG/บรีฟ ให้ pipeline ครบวงจรทันทีโดยไม่ต้องมี key)

> **ทำไมค่าเริ่มต้นถึงยังไม่เจนจริง?** ตัว Claude เองสร้างภาพ/วิดีโอไม่ได้ — มันทำหน้าที่ "คิด + เขียน prompt"
> แล้วส่ง prompt ไปให้บริการ text-to-image / text-to-video เจนออกมาเป็นไฟล์อีกที
> ระบบมีตัวต่อ **Replicate** ให้พร้อมแล้ว (key เดียวใช้ได้ทั้งภาพและวิดีโอ)

**วิธีเปิด (3 ขั้น):**

```bash
# 1. สมัคร Replicate แล้วเอา token — https://replicate.com/account/api-tokens
# 2. ตั้งค่า environment (หรือใส่ใน .env)
export REPLICATE_API_TOKEN=r8_xxxx
export IMAGE_PROVIDER=replicate
export VIDEO_PROVIDER=replicate
# 3. รันตามปกติ — แผนกภาพจะได้ไฟล์ .png / แผนกวิดีโอจะได้ .mp4 จริง
node src/index.js "โจทย์ของคุณ"
```

- ภาพใช้โมเดล `black-forest-labs/flux-schnell` (เร็ว/ถูก), วิดีโอ `minimax/video-01`
  เปลี่ยนได้ที่ `IMAGE_MODEL` / `VIDEO_MODEL` หรือ `src/config.js`
- อยากใช้ผู้ให้บริการอื่น (fal.ai / OpenAI / Google Imagen+Veo)? เพิ่ม branch ใหม่ใน
  [`src/providers/media.js`](src/providers/media.js) ได้เลย โครงสร้างเตรียมไว้แล้ว
- **หมายเหตุค่าใช้จ่าย:** การเจนภาพ/วิดีโอจริงมีค่าใช้จ่ายตามผู้ให้บริการ (วิดีโอแพงกว่าภาพมาก)

## เผยแพร่อัตโนมัติ ต้นทาง→ปลายทาง 📤 (Facebook / Instagram / TikTok)

ระบบทำครบวงจร: โจทย์ → ผลิตคอนเทนต์ → **โพสต์ขึ้นแพลตฟอร์มจริง**

หลังรันแคมเปญ ระบบจะสร้าง `posts.json` (โพสต์พร้อมเผยแพร่ของแต่ละแพลตฟอร์ม) แล้วสั่งโพสต์ได้:

```bash
# ค่าเริ่มต้น = โหมดซ้อม (dry-run) แสดงว่าจะโพสต์อะไร ไม่โพสต์จริง — ปลอดภัย
node src/publish.js "output/<แคมเปญ>"

# โพสต์เฉพาะบางแพลตฟอร์ม
node src/publish.js "output/<แคมเปญ>" facebook,tiktok
```

**เปิดโพสต์จริง** ต้องเชื่อม API ทางการของแต่ละแพลตฟอร์ม (ตั้ง token ใน `.env`) แล้วตั้ง `PUBLISH_LIVE=true`
หรือ `AUTO_PUBLISH=true` เพื่อโพสต์ทันทีหลังรันแคมเปญ

| แพลตฟอร์ม | ต้องมี | หมายเหตุ |
|-----------|--------|----------|
| **Facebook Page** | FB App + Page Token (`pages_manage_posts`) | อัปโหลดรูป/วิดีโอตรงได้ · ตั้งเวลาโพสต์ได้ |
| **Instagram** | IG Business ผูก FB Page + Token + `MEDIA_BASE_URL` | ต้อง host สื่อเป็น URL สาธารณะก่อน |
| **TikTok** | Developer App + token (`video.publish`) | ต้องผ่าน app review ของ TikTok · วิดีโอเท่านั้น |

> ⚠️ แนะนำ: รีวิวคอนเทนต์ก่อนโพสต์จริง (ค่าเริ่มต้นจึงเป็น dry-run และไม่ auto-publish)
> ดู token ทั้งหมดใน [`.env.example`](.env.example)
