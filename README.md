# ระบบ AI ผลิตคอนเทนต์แบบหลายแผนก 🎬

ระบบ AI ที่ทำงานอัตโนมัติแบบ **"เอเจนซี่ทั้งทีม"** — แบ่งเป็นหลายแผนก แต่ละแผนกดูแลคนละส่วน
(กลยุทธ์ / เทรนด์ / เขียนบท / วิดีโอ / ภาพ / จัดโพสต์ตามแพลตฟอร์ม / ตรวจแบรนด์)
โดยมี **"ผู้จัดการ" (AI)** คอยแตกงานและสั่งงานแต่ละแผนกให้เองอัตโนมัติ

> รับโจทย์เดียว เช่น *"ทำแคมเปญเปิดตัวสินค้าใหม่ ลง TikTok/IG/FB"* →
> ระบบวางแผน สั่งงานทุกแผนก แล้วส่งกลับเป็น **แพ็กเกจคอนเทนต์พร้อมโพสต์**

## แผนกในระบบ

1. 🧭 **วางแผนกลยุทธ์คอนเทนต์** — แปลงโจทย์เป็นแผน + รายการชิ้นงาน
2. 🔥 **วิจัยเทรนด์ & แฮชแท็ก** — มุมมาแรง + แฮชแท็ก/คีย์เวิร์ด
3. ✍️ **เขียนบท & แคปชั่น** — hook, สคริปต์, แคปชั่น, CTA
4. 🎥 **วิดีโอ** — สตอรี่บอร์ด + ไดเรกชัน + prompt text-to-video
5. 🎨 **ภาพ & กราฟิก** — ทิศทางภาพ + image prompt
6. 📱 **จัดโพสต์ตามแพลตฟอร์ม** — ปรับคอนเทนต์ให้เข้ากับแต่ละแพลตฟอร์ม + เวลาโพสต์
7. ✅ **ตรวจแบรนด์ & คุณภาพ** — ตรวจก่อนปล่อย

ดูรายละเอียดสถาปัตยกรรมได้ที่ [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## วิธีใช้งาน

```bash
# 1. ติดตั้ง dependency
npm install

# 2. ตั้งค่า API key (เลือกอย่างใดอย่างหนึ่ง)
export ANTHROPIC_API_KEY=sk-ant-xxxx
#   หรือ คัดลอก .env.example เป็น .env แล้วใส่ค่า

# 3. รันด้วยโจทย์ของคุณ
node src/index.js "ทำคอนเทนต์เปิดตัวร้านกาแฟใหม่ ลง TikTok และ Instagram โทนอบอุ่น"

# หรือรันตัวอย่างสำเร็จรูป
npm run demo
```

## โครงสร้างโปรเจกต์

```
src/
├── index.js              # จุดเริ่มต้น (CLI)
├── config.js             # ตั้งค่าโมเดล / effort / จำนวนรอบ
├── orchestrator.js       # "ผู้จัดการ" — แตกงาน สั่งงาน รวบรวม (agentic loop + tool use)
└── departments/
    └── index.js          # นิยามทุกแผนก (หน้าที่ + system prompt)
docs/
└── ARCHITECTURE.md       # แผนผังและรายละเอียดระบบ
```

## เพิ่มแผนกใหม่

แค่เพิ่ม object ใน `src/departments/index.js` — ระบบจะสร้าง tool ให้ "ผู้จัดการ" เรียกใช้อัตโนมัติ

```js
{
  key: 'influencer',
  name: 'แผนกประสานอินฟลูเอนเซอร์',
  description: 'จับคู่แคมเปญกับ KOL ที่เหมาะสม และร่างบรีฟส่งอินฟลูฯ',
  systemPrompt: `คุณคือแผนกประสานอินฟลูเอนเซอร์ ...`,
}
```

## หมายเหตุ

- แผนกภาพ/วิดีโอส่งออกเป็น **prompt** — ต่อ API เครื่องมือ text-to-image / text-to-video
  เพื่อ render ไฟล์จริงได้ (ดูหัวข้อ "การต่อยอด" ใน `docs/ARCHITECTURE.md`)
- ใช้โมเดล `claude-opus-4-8` เป็นค่าเริ่มต้น ปรับได้ที่ `src/config.js`
