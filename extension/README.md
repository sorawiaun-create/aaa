# Chobtham GMV Max Controller (Chrome Extension)

Extension ที่ฝังตัวในหน้า **ads.tiktok.com** ใช้ session ที่คุณล็อกอินอยู่ เพื่อ
มอนิเตอร์และควบคุมแคมเปญ GMV Max (แนวทางเดียวกับเครื่องมืออย่าง betafit)

> ⚠️ วิธีนี้ทำงานนอก API ทางการของ TikTok — มีความเสี่ยงเรื่องข้อกำหนดการใช้งาน
> (ToS) และการถูกระงับบัญชี ใช้ด้วยความเข้าใจความเสี่ยงนี้

## เวอร์ชันนี้ทำอะไรได้ (v0.2 — Side Panel + ปิด/เปิดจริง)
- ✅ **Side Panel** ล็อกค้างข้างขวา (ไม่หายเวลากดหน้าอื่น) — คลิกไอคอน Extension เพื่อเปิด
- ✅ แสดงรายการ **แคมเปญ GMV Max** (ดึงจากข้อมูลที่หน้า TikTok โหลด)
- ✅ ปุ่ม **เปิด/ปิด** แคมเปญ (ใช้ endpoint ภายในจริงของ TikTok)
- ✅ **แจ้งเตือน Telegram** + ปุ่มทดสอบ
- ✅ สวิตช์เปิด/ปิดบอท + ตั้งรอบตรวจ

## ปุ่มเปิด/ปิดใช้งานยังไง (สำคัญ)
ครั้งแรกต้อง "สอน" คำสั่งให้ระบบก่อน:
1. ในหน้า TikTok ให้ **ปิดแคมเปญ 1 ตัวด้วยมือ 1 ครั้ง**
2. ระบบจะจดจำคำสั่ง (recipe) ไว้ → หลังจากนั้นปุ่มเปิด/ปิดในแผงข้างจะใช้ได้กับทุกตัว

## ยังไม่ได้ทำ (ขั้นถัดไป)
- รันกฎอัตโนมัติ (ROI/งบ/ออร์เดอร์ → ปิด/ปรับงบ เอง)
- ปรับงบ / สร้างแคมเปญใหม่อัตโนมัติ
- คุมหลายช่อง

## วิธีติดตั้ง (ไม่เกิน 5 นาที)
1. **แตกไฟล์** `chobtham-gmvmax-extension.zip` → ได้โฟลเดอร์ `extension`
2. เปิด Chrome พิมพ์ที่ช่อง URL: `chrome://extensions` กด Enter
3. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
4. กด **Load unpacked** → เลือก**โฟลเดอร์ `extension`** (เลือกทั้งโฟลเดอร์ ไม่ใช่ไฟล์ข้างใน)
5. กดไอคอนต่อจิ๊กซอว์ (Extensions) บนแถบ Chrome → **ปักหมุด** "GMV Max Controller"
6. เปิดหน้า **ads.tiktok.com** → ไปหน้า **GMV Max** → ล็อกอินให้เรียบร้อย

## วิธีใช้ (โหมด Learn — ขั้นตอนสำคัญตอนนี้)
1. เปิดหน้า GMV Max บน ads.tiktok.com
2. ลอง **กดปุ่มต่างๆ** เช่น เปิด/ปิดแคมเปญ 1 ตัว, เปลี่ยนงบ
3. คลิกไอคอน Extension → ดูส่วน **"API ภายในที่จับได้"** → จะเห็นรายการ endpoint
4. ส่งรายการนั้นกลับมา เพื่อให้เราต่อระบบปิด/เปิด/ปรับงบ อัตโนมัติ

## ตั้งค่า Telegram (ไม่บังคับ)
1. สร้างบอทกับ **@BotFather** ใน Telegram → ได้ **Bot Token**
2. เริ่มแชตกับบอท แล้วหา **Chat ID** (เช่นผ่าน @userinfobot)
3. กรอกทั้งสองค่าใน popup → กด **บันทึก** → **ทดสอบส่ง**

## ไฟล์ในโปรเจกต์
- `manifest.json` — ตั้งค่า Extension (MV3)
- `injected.js` — ดัก fetch/XHR ในหน้าเว็บ (โหมด Learn)
- `content.js` — สะพานเชื่อม + เรียก API ในหน้า TikTok (สำหรับ automation)
- `background.js` — ตัวจับเวลา + ส่ง Telegram
- `popup.html` / `popup.js` — หน้าตั้งค่า
