========================================================
  วิธีรัน "ระบบจัดการแอดอัตโนมัติ" บนคอมของคุณเอง (Windows)
========================================================

ระบบนี้คุยกับ Facebook โดยตรง ไม่เกี่ยวกับ GitHub เลย
เพราะงั้นถึง GitHub จะยังปลดล็อกบัญชีไม่เสร็จ แอดของคุณก็จะถูก
จัดการต่อได้ตามปกติ ถ้าเปิดคอมและเปิดโปรแกรมนี้ไว้

** พอเปิดโปรแกรม เบราว์เซอร์จะเด้งขึ้น "หน้าโคม" หน้าตาเหมือนเว็บเดิมทุกอย่าง **
   ดูภาพรวม / ตั้งกฎ / กระดานแอด / สั่งเปิด-ปิด ได้เหมือนเดิม
   (ถ้าเบราว์เซอร์ไม่เด้งเอง เปิดเองที่:  http://127.0.0.1:8765 )


------------------------------------------------
ทำครั้งเดียว: ติดตั้ง Python (ถ้ายังไม่มี)
------------------------------------------------
1. เข้า  https://www.python.org/downloads/
2. กดปุ่มเหลือง "Download Python" แล้วเปิดไฟล์ที่โหลดมา
3. ** สำคัญมาก ** ในหน้าจอแรกของตัวติดตั้ง
   ให้ติ๊กช่องด้านล่างที่เขียนว่า  "Add python.exe to PATH"  ก่อน
   แล้วค่อยกด  Install Now
4. ติดตั้งเสร็จกด Close


------------------------------------------------
วิธีเริ่มใช้งาน
------------------------------------------------
1. ดับเบิลคลิกไฟล์  START.bat  (อยู่โฟลเดอร์เดียวกับไฟล์นี้)

2. ครั้งแรกมันจะเปิด Notepad ไฟล์ token.txt ให้
   - ลบข้อความเดิมในนั้นออกให้หมด
   - วาง Facebook access token ของคุณลงไป (บรรทัดเดียว)
   - กดเซฟ (Ctrl+S) แล้วปิด Notepad

3. ดับเบิลคลิก  START.bat  อีกครั้ง
   - ครั้งแรกจะติดตั้งตัวช่วยสักครู่ (1-3 นาที) รอได้เลย
   - เสร็จแล้ว เบราว์เซอร์จะเด้งเปิด "หน้าโคม" ให้อัตโนมัติ = ใช้ได้!

4. ใช้งานหน้าโคมในเบราว์เซอร์ได้เหมือนเว็บเดิมทุกอย่าง
   - ดูภาพรวม ตั้งกฎ กระดานแอด สั่งเปิด-ปิด ฯลฯ
   - ระบบจะเช็คและจัดการแอดให้เองทุก 10 นาที
   - ปล่อยหน้าต่างสีดำเปิดไว้ (ปิด = ระบบหยุด)
   - ถ้าเบราว์เซอร์ไม่เด้งเอง เปิดเองที่:  http://127.0.0.1:8765


------------------------------------------------
ต้องรู้
------------------------------------------------
- อยากให้ระบบทำงาน = ต้องเปิดคอม + เปิดหน้าต่าง START.bat ไว้
  ปิดคอมหรือปิดหน้าต่าง = ระบบหยุด (แอดจะไม่ถูกจัดการช่วงนั้น)

- จะหยุดชั่วคราว: กด Ctrl+C ในหน้าต่าง หรือปิดหน้าต่างไปเลย
  จะเริ่มใหม่: ดับเบิลคลิก START.bat อีกที

- ไฟล์ token.txt เก็บโทเคนของคุณไว้ในเครื่องเท่านั้น
  ** ห้ามส่งไฟล์ token.txt ให้ใคร และห้ามอัปขึ้นเน็ต **

- กฎการเปิด/ปิด/ปรับงบ ใช้กฎชุดเดียวกับบนเว็บ (อ่านจากไฟล์ config.json)


------------------------------------------------
ถ้าติดปัญหา
------------------------------------------------
- ขึ้น "ไม่พบ Python": ยังไม่ได้ติดตั้ง Python หรือลืมติ๊ก "Add to PATH"
  -> ติดตั้งใหม่ตามด้านบน อย่าลืมติ๊กช่องนั้น

- ขึ้นเรื่อง token หรือ "Call was not successful": โทเคนหมดอายุ/ผิด
  -> เปิด token.txt วางโทเคนใหม่ เซฟ แล้วรัน START.bat ใหม่

- อย่างอื่น: ถ่ายรูปหน้าจอส่งมาถามได้เลย
