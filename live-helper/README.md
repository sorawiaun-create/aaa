# ผู้ช่วยไลฟ์ TikTok — ปักหมุดอัตโนมัติ + AI ตอบคอมเมนต์

ส่วนขยาย Chrome (Manifest V3) ที่ทำงาน **ในหน้าคอนโซล LIVE ของ TikTok Shop** โดยตรง

1. **ปักหมุดสินค้าอัตโนมัติ** — ปักหมุด "ตะกร้าที่ 1" (หรือลำดับไหนก็ได้) แล้วคอยกดปุ่ม
   **“+30 วินาที”** ที่ TikTok ขึ้นให้ทุกครั้งที่หมุดใกล้หมดเวลา หมุดจึงอยู่ยาวโดยคลิกน้อยที่สุด
   (เลือกเป็นแบบยกเลิกแล้วปักใหม่ทุก 30 วิ/1 นาที ได้ ถ้าอยากให้การ์ดเด้งขึ้นจอผู้ชมซ้ำ)
2. **AI ตอบคอมเมนต์อัตโนมัติ** — อ่านคอมเมนต์ในแชทไลฟ์ ส่งให้ Claude ร่างคำตอบสั้น ๆ
   ภาษาไทยไม่เกิน 100 ตัวอักษร แล้วพิมพ์ส่งกลับในแชทให้เอง

> TikTok ไม่มี API สาธารณะให้ปักหมุดสินค้าหรือส่งแชทไลฟ์ ระบบนี้จึงทำงานแบบ
> “กดปุ่มบนหน้าเว็บแทนเรา” — ต้อง **เปิดหน้าคอนโซล LIVE ค้างไว้** ตลอดเวลา

## ติดตั้ง

1. เปิด Chrome/Edge → `chrome://extensions`
2. เปิด **โหมดนักพัฒนา (Developer mode)** มุมขวาบน
3. กด **โหลดส่วนขยายที่แตกไฟล์แล้ว (Load unpacked)** → เลือกโฟลเดอร์ `live-helper/`
   (ต้องเป็นโฟลเดอร์ที่มีไฟล์ `manifest.json` อยู่ข้างใน)
4. เปิด **TikTok LIVE Manager** (คอนโซล LIVE) จะเห็นแผงควบคุมลอยอยู่มุมขวาล่าง

### เปิดไม่ขึ้น / ไม่เห็นแผงควบคุม

- **ถ้าหน้าคอนโซล LIVE เปิดค้างอยู่ก่อนติดตั้ง** ให้กด `F5` รีเฟรชหนึ่งครั้ง
  (Chrome จะฉีดสคริปต์เข้าเฉพาะหน้าที่โหลดหลังติดตั้งเท่านั้น)
- **ใช้ได้ในเบราว์เซอร์หนึ่งแต่อีกอันไม่ได้?** เช็กก่อนว่าทั้งสองเบราว์เซอร์ลง **เวอร์ชันเดียวกัน**
  — ส่วนขยายนี้ไม่มีโค้ดที่ผูกกับเบราว์เซอร์ใดเบราว์เซอร์หนึ่ง อาการต่างกันมักมาจากลงคนละเวอร์ชัน
  (และค่าที่ตั้งไว้ก็เก็บแยกกันคนละเบราว์เซอร์)
- กด **ไอคอนส่วนขยาย** บนแถบเครื่องมือ (รูปจิ๊กซอว์ → ปักหมุด "ผู้ช่วยไลฟ์ TikTok" ไว้)
  จะมีหน้าต่างบอกสถานะ และปุ่ม **"เปิดแผงควบคุมในหน้านี้"** สั่งเปิดแผงได้เอง
- ที่อยู่คอนโซล LIVE ต่างกันตามประเทศ/บัญชี — ให้เปิดหน้าคอนโซลของคุณเองแล้วกด
  **"จำหน้านี้ไว้เป็นคอนโซล LIVE ของฉัน"** ในป๊อปอัป ครั้งต่อไปกดปุ่มเดียวเข้าหน้าเดิมได้เลย
- แผงจะโผล่เองเฉพาะหน้าที่ดูเหมือนคอนโซล LIVE เท่านั้น หน้า TikTok อื่น ๆ จะเงียบไว้
  แต่เรียกเปิดจากไอคอนได้ตลอด

## วิธีใช้

### แท็บ "ปักหมุด"
| ช่อง | ความหมาย |
|---|---|
| ปักหมุดตะกร้าที่ | ลำดับสินค้าในรายการ (ค่าเริ่มต้น = 1) |
| ปักซ้ำทุก (วินาที) | 30 / 60 / 120 หรือพิมพ์เอง — **ขั้นต่ำ 15 วินาที** |
| วิธีทำให้หมุดอยู่ต่อ | **กด “+30 วิ” ทุกครั้งที่โผล่** (ค่าเริ่มต้น) · ยกเลิกแล้วปักใหม่ · ปักครั้งเดียวแล้วปล่อย |
| โหมดซ้อม | ไม่คลิกจริง แค่ลงบันทึกว่าจะกดอะไร ใช้ทดสอบก่อนไลฟ์จริง |

> **ถ้าปักผิดใบ** — หน้าคอนโซลมีปุ่ม “ปักหมุด” อยู่หลายที่ (คูปอง, การแจกรางวัล, แถบรายการสินค้ารวม)
> ระบบคัดออกให้แล้วโดยดูจากเนื้อหาในการ์ด กดปุ่ม **“ตรวจก่อนปัก — จะปักตัวไหน?”**
> เพื่อดูชื่อสินค้าที่ระบบเล็งอยู่ (จะขึ้นกรอบสีชมพูรอบการ์ดนั้นในหน้าเว็บ) ก่อนกดเริ่มจริง

กด **เริ่มปักหมุดอัตโนมัติ** แล้วดูสถานะ (ปักหมุดอยู่ / รอบถัดไปอีกกี่วินาที) ได้ที่กล่องด้านบน

### สองวิธีทำให้หมุดอยู่ต่อ — เลือกให้เหมาะกับหน้างาน

| | **กด “+30 วิ” ทุกครั้งที่โผล่** (ค่าเริ่มต้น) | **ยกเลิกแล้วปักใหม่** |
|---|---|---|
| จำนวนคลิก | 1 ครั้ง / 30 วินาที | 2 ครั้ง / รอบ (ยกเลิก + ปัก) |
| การ์ดเด้งขึ้นจอผู้ชม | ไม่เด้งใหม่ (หมุดค้างอยู่เดิม) | เด้งใหม่ทุกรอบ |
| ความเสี่ยงเจอจิ๊กซอว์ | ต่ำสุด — ใช้ปุ่มที่ TikTok ทำมาให้ | สูงกว่ามาก |
| เหมาะกับ | ไลฟ์ยาว ๆ อยากให้หมุดค้างไว้เฉย ๆ | ช่วงเร่งปิดการขาย และรับความเสี่ยงได้ |

โหมด “+30 วิ” ทำงานแบบเฝ้าดู: **ปุ่มโผล่เมื่อไหร่กดทันที** (เว้นอย่างน้อย 5 วินาทีต่อครั้ง)
ไม่ต้องรอรอบ และถ้าหมุดหลุดไปแล้วจริง ๆ จะปักให้ใหม่ครั้งเดียว
ช่อง “ปักซ้ำทุก (วินาที)” มีผลเฉพาะโหมดยกเลิกแล้วปักใหม่เท่านั้น

ระบบมี **เพดานคลิก 8 ครั้ง/นาที** (ตั้งได้ 2–30) ถ้าเกินนี้แปลว่าโค้ดรวนหรือเล็งปุ่มผิด
มันจะ **หยุดตัวเองทันที** พร้อมขึ้นแถบเตือน — กันไม่ให้ไปกดรัวใส่หน้าเว็บจริง

> ถ้าหาปุ่ม “+30 วิ” ไม่เจอ (ธีมของแต่ละบัญชีไม่เหมือนกัน) ใช้ปุ่ม **“จิ้มเลือกปุ่ม +30 วิ”**
> แล้วคลิกที่ปุ่มนั้นบนหน้าเว็บตอนที่มันโผล่ขึ้นมา ระบบจะจำไว้ให้

### แท็บ "สินค้า" — ข้อมูลที่ AI ใช้ตอบลูกค้า

หน้าคอนโซล LIVE มีข้อมูลสินค้าแค่ **ชื่อกับราคา** เท่านั้น (ไม่มีสี ไซส์ ค่าส่ง ของแถม)
ระบบจึงทำงาน 2 ชั้น:

1. **ดึงอัตโนมัติ** — กด “ดึงชื่อ+ราคาจากหน้านี้” จะอ่านชื่อ/ราคาจากการ์ดสินค้าในไลฟ์มาให้
2. **กรอกรายละเอียดเอง (ทำครั้งเดียว)** — สี/ไซส์ที่มี, ค่าส่ง, ของแถม, รับประกัน, วัสดุ ฯลฯ
   ใส่ไว้ในช่องของตะกร้านั้น ๆ

ตอนตอบลูกค้า AI จะได้รับทั้งรายการสินค้าในไลฟ์และรายละเอียดที่กรอกไว้ พร้อมคำสั่งว่า
คำว่า “ตัวนี้ / อันนี้” หมายถึงสินค้าตะกร้าที่ตั้งไว้ในแท็บปักหมุด
ถ้าไม่มีข้อมูล AI ถูกสั่งให้ตอบว่า “เดี๋ยวแม่ค้าตอบในไลฟ์” แทนการเดา

### แท็บ "AI ตอบแชท"
1. ไปที่แท็บ “ตั้งค่า” เลือก **ใช้ AI ของ** — รองรับสองค่าย:
   - **Claude (Anthropic)** — คีย์จาก console.anthropic.com · รุ่น `claude-opus-5` (ฉลาดสุด)
     หรือ `claude-haiku-4-5` (เร็ว/ถูกกว่ามาก เหมาะกับแชทไลฟ์)
   - **GPT (OpenAI)** — คีย์จาก platform.openai.com · รุ่นแนะนำ `gpt-4o-mini` (เล็ก/ถูก)
2. ใส่ API key ของค่ายนั้น — **เก็บแยกกันคนละช่อง** สลับค่ายไปมาได้โดยไม่ต้องกรอกใหม่
   (ช่อง “รุ่น” พิมพ์ชื่อรุ่นเองได้ ถ้าใส่ผิดจะขึ้นว่า “ไม่พบรุ่น …” ตอนกดทดสอบ)
3. กรอก **กติกาเพิ่มเติม** เช่น ค่าส่ง โปรโมชั่น ของแถม เพื่อกัน AI ตอบมั่ว
4. **แนะนำให้เปิด “โหมดร่าง” ก่อน** — AI จะคิดคำตอบแล้วโชว์ในแท็บ “บันทึก” โดยยังไม่ส่งจริง
   พอใจกับคำตอบแล้วค่อยปิดโหมดร่าง

### ลูกค้าถามสินค้าตะกร้าอื่น

ในไลฟ์ลูกค้าจะเรียกสินค้าด้วยเลข — “หมายเลข14”, “เบอร์ 3”, “ตัวที่ 2” หรือพิมพ์เลขมาโดด ๆ (“14”)
ระบบอ่านเลขนั้นออก แล้วดูว่าเป็นสินค้าหลัก (ตะกร้าที่ตั้งไว้ในแท็บปักหมุด) หรือตัวอื่น

สินค้าตัวอื่นไม่ได้อยู่หน้ากล้อง ระบบจึง **สั่งห้าม AI รับปากว่าจะหยิบมาโชว์ / เดี๋ยวโชว์ให้ดู**
ให้ชี้ไปที่ตะกร้าแทนเสมอ

ถ้าเป็นตัวอื่น เลือกได้ 3 แบบในแท็บ “AI ตอบแชท”:

| โหมด | ผลลัพธ์ |
|---|---|
| **ตอบเท่าที่มีข้อมูล** (ค่าเริ่มต้น) | ตอบชื่อ/ราคา/รายละเอียดที่มีจริงเท่านั้น ไม่มีข้อมูลก็ชวนกดเข้าไปดูในตะกร้า |
| **ตอบสั้น ชี้ไปที่ตะกร้า** | ไม่ลงรายละเอียดใด ๆ ตอบแค่ว่ากดเข้าไปดูในตะกร้าได้เลย |
| **ไม่ตอบ (แม่ค้าตอบเอง)** | เงียบไว้ แต่ยังขึ้นเตือนในบันทึกให้คุณเห็น |

ทุกครั้งที่มีคนถามถึงตะกร้าอื่น จะขึ้น **บรรทัดสีน้ำเงินในแท็บ “บันทึก”** และนับไว้ในแถบสถานะ
(“ถามตะกร้าอื่น: 3”) จะได้เหลือบดูแล้วพูดถึงในไลฟ์ได้ทัน

ติ๊ก **“ตอบเสร็จแล้วชวนกลับมาที่สินค้าหลัก”** ไว้ AI จะปิดท้ายด้วยการดึงกลับมาที่ตัวที่กำลังขาย

แถบสถานะบอก **“เห็นคอมเมนต์ล่าสุด N วิที่แล้ว”** — ถ้าเลขนี้ไต่ขึ้นเรื่อย ๆ ทั้งที่ในไลฟ์มีคนพิมพ์อยู่
แปลว่าระบบอ่านแชทไม่เห็นแล้ว (ปกติยามเฝ้าจะต่อให้ใหม่เองภายใน 5 วินาที)

ปุ่ม **"ทดสอบคำตอบ"** ใต้ปุ่มเริ่ม — พิมพ์คำถามสมมติแล้วกดดูได้เลยว่า AI ตอบว่าอะไร
โดยไม่ต้องรอลูกค้าคอมเมนต์จริง (ใช้เช็กว่า API key ใช้ได้และข้อมูลสินค้าครบไหม)

### ขอบเขตการตอบ

ค่าเริ่มต้นคือ **ตอบทุกคอมเมนต์** — รวมคำทักทาย คำชม อีโมจิ ไม่ใช่เฉพาะคำถาม
(สลับเป็น “เฉพาะคำถาม” ได้ในช่อง “ขอบเขตการตอบ”) และ AI ถูกสั่งไว้ว่า

- **ห้ามตอบเป็นประโยคเดิมซ้ำ ๆ** ทุกครั้งจะเห็นประโยค 5 อันล่าสุดที่เพิ่งตอบไป
  พร้อมคำสั่งว่าห้ามซ้ำหรือใกล้เคียงของเดิม
- ตัวอย่างประโยคที่ให้ไว้ (เช่น “กดเข้าไปดูในตะกร้าได้เลยค่ะ”) เป็นแค่ **แนว**
  ไม่ใช่ข้อความสำเร็จรูป — สั่งให้เปลี่ยนคำพูดเองทุกครั้ง
- ตอบว่า SKIP เฉพาะข้อความหยาบคาย ก่อกวน สแปม หรือโฆษณาร้านอื่นเท่านั้น

ปุ่มลัด **“ตอบถี่ (คนเยอะ)”** = 25 ข้อความ/นาที เว้นคนเดิม 5 วิ ·
**“ตอบพอประมาณ”** = 10 ข้อความ/นาที เว้นคนเดิม 45 วิ

### ตอบไปสักพักแล้วเงียบไปเลย?

ในโค้ดไม่มีลิมิตจำนวนครั้งต่อไลฟ์ — มีแค่ **จำนวนต่อนาที** (ค่าเริ่มต้น 15) ซึ่งครบแล้วรอ
นาทีถัดไปก็ตอบต่อเอง ถ้าเงียบยาวให้ดูสองอย่างนี้ในแท็บ “บันทึก”:

| สิ่งที่เห็นในบันทึก | แปลว่า | ทำยังไง |
|---|---|---|
| `กล่องแชทถูกวาดใหม่ — ต่อระบบอ่านคอมเมนต์ใหม่ให้แล้ว` | TikTok วาดหน้าแชทใหม่ ระบบต่อให้เองแล้ว | ไม่ต้องทำอะไร ถ้าขึ้นถี่มากค่อยบอก |
| `ส่งไม่ออก 3 ครั้งติด — TikTok น่าจะจำกัดการส่งแชท` | ระบบพิมพ์ลงช่องแล้วแต่ข้อความไม่ถูกส่งออก | ลด “ตอบได้ไม่เกิน (ข้อความ/นาที)” เหลือ 5–8 |
| `AI ไม่ตอบกลับภายใน 25 วินาที` / `รอคำตอบจาก AI นานเกิน 1 นาที` | คำขอค้าง (service worker หลับ) — ระบบปลดล็อกให้เองแล้ว | ไม่ต้องทำอะไร ถ้าเจอบ่อยให้เปลี่ยนไปใช้รุ่นเล็กที่ตอบเร็วกว่า |
| `AI ตอบไม่สำเร็จ: เรียกถี่เกินโควตา (429)` | เครดิตหมดหรือยิงถี่เกินโควตาของค่าย AI | เช็กเครดิตในบัญชี AI ที่ใช้อยู่ |

ตัวกันพลาดที่ใส่ไว้ให้:
- ตอบได้ไม่เกิน N ข้อความต่อนาที (ค่าเริ่มต้น 15)
- คนเดิมต้องเว้นระยะก่อนตอบซ้ำ (ค่าเริ่มต้น 20 วินาที)
- ข้ามข้อความระบบของ TikTok เอง (“เข้าร่วมแล้ว”, “ได้ซื้อสินค้า”, “กำลังดูสินค้ารายการนี้”)
- ไม่ตอบข้อความที่ตัวเองเพิ่งส่งไป และไม่ตอบคอมเมนต์ซ้ำ
- คำต้องห้าม (เจอแล้วไม่ตอบเลย)
- AI ถูกสั่งให้ตอบว่า `SKIP` เมื่อเจอคอมเมนต์ก่อกวน/สแปม ระบบจะข้ามให้อัตโนมัติ

### ถ้าหาปุ่มไม่เจอ
หน้าเว็บ TikTok เปลี่ยนโครงสร้างบ่อย ระบบจึงหาปุ่มจาก **ข้อความบนปุ่ม** (เช่น “ปักหมุด”)
ถ้าในบันทึกขึ้นว่าหาไม่เจอ ให้ใช้ปุ่ม **“จิ้มเลือกเอง”** แล้วคลิกที่ปุ่ม/ช่องนั้นบนหน้าเว็บตรง ๆ
(กด Esc เพื่อยกเลิก) ระบบจะจำตำแหน่งไว้ใช้ต่อ

## เจอจิ๊กซอว์ให้ยืนยันตัวตน (Verify to continue)

หน้าจิ๊กซอว์คือ TikTok บอกว่า **กิจกรรมในหน้านี้ถี่เกินไปจนดูเหมือนบอท** ส่วนขยายจะ:

1. **หยุดทุกระบบทันที** ที่ตรวจเจอ (ทั้งปักหมุดและ AI ตอบแชท)
2. ส่งเสียงเตือน + ขึ้นแถบแดงบนแผง + เปลี่ยนชื่อแท็บเป็น “⚠️ ยืนยันตัวตน”
3. **รอให้คุณแก้จิ๊กซอว์เอง** — ส่วนขยายจะไม่ยุ่งกับหน้ายืนยันเด็ดขาด
4. พอยืนยันผ่าน จะทำงานต่อให้เอง และ **ยืดรอบปักหมุดอัตโนมัติ** (เจอ 1 ครั้ง = ×1.5,
   2 ครั้ง = ×2 … สูงสุด ×4) เพื่อลดโอกาสโดนซ้ำ

**ถ้ายังเจอบ่อย ให้ลดกิจกรรมลงตามนี้ (เรียงตามผลมาก→น้อย)**

| ทำอะไร | เหตุผล |
|---|---|
| ใช้โหมด **“กด +30 วิ ทุกครั้งที่โผล่”** (ค่าเริ่มต้น) | คลิกเดียวต่อ 30 วิ และเป็นปุ่มที่ TikTok ทำมาให้ใช้ |
| ถ้าใช้โหมดยกเลิกแล้วปักใหม่ ให้เพิ่มรอบเป็น **60–120 วินาที** | รอบ 30 วิ = คลิก 4 ครั้ง/นาที ถี่มาก |
| ลด **จำนวนตอบต่อนาที** เหลือ 6–8 | ส่งแชทรัวก็นับเป็นกิจกรรมถี่เหมือนกัน |
| อย่าเปิดหลายแท็บของคอนโซล LIVE พร้อมกัน | นับรวมกันหมด |

ระบบจะสุ่มจังหวะบวก/ลบตามค่า “สุ่มจังหวะ” (เริ่มต้น ±15%) อยู่แล้ว จะได้ไม่กดตรงเป๊ะทุกวินาที

> ⚠️ ส่วนขยายนี้ **ไม่มีและจะไม่มี** ระบบแก้จิ๊กซอว์อัตโนมัติ การพยายามหลบด่านยืนยัน
> เสี่ยงต่อการถูกจำกัดหรือระงับบัญชีร้าน — ทางที่ถูกคือลดความถี่ลงให้อยู่ในระดับที่ปกติ

## ความปลอดภัยและข้อควรรู้

- **API key เก็บใน `chrome.storage.local` ของเครื่องคุณ** และถูกใช้เฉพาะใน service worker
  ของส่วนขยาย — ไม่ถูกส่งเข้าไปในหน้าเว็บ TikTok และยิงออกได้เฉพาะ `api.anthropic.com`
  กับ `api.openai.com` เท่านั้น
- ทุกครั้งที่เปิดหน้าใหม่ ระบบจะเริ่มที่สถานะ **ปิด** เสมอ ต้องกดเริ่มเอง
- การกดปุ่มรัว ๆ เสี่ยงถูกระบบมองว่าผิดปกติ จึงล็อกรอบปักหมุดขั้นต่ำไว้ที่ 15 วินาที
  และจำกัดจำนวนข้อความที่ AI ตอบต่อนาที — ไม่แนะนำให้ตั้งถี่กว่านี้
- ตรวจคำตอบของ AI สม่ำเสมอ โดยเฉพาะเรื่องราคา/โปร/ค่าส่ง ซึ่งเป็นข้อมูลที่ผิดแล้วเสียหายจริง

## โครงไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `manifest.json` | ประกาศส่วนขยาย, หน้าเว็บที่ให้ทำงาน, สิทธิ์เรียก `api.anthropic.com` |
| `src/core.js` | ตรรกะล้วน ๆ (ค่าตั้งต้น, ตัวกรองคอมเมนต์, จังหวะปักหมุด, สร้าง prompt) — มีเทสต์ครอบ |
| `src/dom.js` | หาปุ่ม/ช่องแชทบนหน้า TikTok, พิมพ์ข้อความ, โหมดจิ้มเลือก element |
| `src/autopin.js` | เครื่องปักหมุดอัตโนมัติ |
| `src/chat.js` | เครื่องอ่านคอมเมนต์ → ขอคำตอบจาก AI → ส่งกลับ |
| `src/panel.js` | แผงควบคุมในหน้าเว็บ + บันทึกค่า |
| `src/background.js` | service worker ตัวเดียวที่เรียก AI (Claude หรือ GPT) |
| `popup.html` / `popup.js` | หน้าต่างที่เด้งขึ้นเมื่อกดไอคอนส่วนขยาย (เช็กสถานะ/สั่งเปิดแผง) |

เทสต์ตรรกะอยู่ที่ `test/live-helper.test.js` (รันด้วย `npm test` ที่โฟลเดอร์หลัก)
