# Content OS — Marketing System

ระบบตามที่เห็นในวิดีโอ: หน้า **แผนผังระบบ (Marketing System)** ที่กดเข้าไปดูได้ทุกกล่อง
พร้อมหน้าย่อยครบทั้ง 9 หน้า ใช้ **ข้อมูลตัวอย่าง (demo data)** ทั้งหมด

## วิธีเปิด

ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร ไม่ต้อง build — **ดับเบิลคลิก `index.html`** เปิดในเบราว์เซอร์ได้เลย
(หรือลากไฟล์ไปวางในหน้าต่าง Chrome) เหมือนในวิดีโอที่เปิดจาก `file://`

จะแชร์ให้คนอื่นก็แค่ส่งไฟล์ `index.html` ไฟล์เดียว

## โครงสร้างระบบ

```
CORE · สมองของระบบ            ← กดปุ่ม ? ที่มุมการ์ดเพื่อดูคำอธิบาย
├── Claude          — สั่งงานทุกอย่างผ่านตัวเดียว
├── Context Memory  — จำธุรกิจ/โทน/ลูกค้าของคุณได้
├── Always-On       — ตื่นทำงานเองทุกเช้า 6:00
└── Connectors      — ต่อ IG · FB · TikTok · YouTube · Meta Ads · Sheets

Data วิเคราะห์ผล        ทำคอนเทนต์            โฆษณา
├── ANALYTICS          ├── คลัง HOOK         └── ADS · FB/IG
├── ติดตามคู่แข่ง       ├── ปฏิทิน CONTENT         (CAMPAIGN ไหนคุ้ม)
└── เทรนด์วันนี้         └── ตั้งเวลาโพสต์

OUTPUT · สิ่งที่คุณเห็นทุกเช้า
└── ภาพรวม + รายงานสรุปทุกเช้า
```

## หน้าที่มีทั้งหมด

| หน้า | มีอะไร |
| --- | --- |
| แผนผังระบบ | ไดอะแกรมทั้งระบบ กดกล่องไหนก็เข้าไปดูข้างในได้ |
| ภาพรวม | KPI 4 ตัว + สรุปเช้านี้โดย Claude + สิ่งที่ควรทำวันนี้ |
| ANALYTICS | Views / Saves / Profile พร้อมกราฟ, Top 5 คอนเทนต์มาแรง, ที่ยังไม่เวิร์ค |
| ติดตามคู่แข่ง | 8 creators, ความเคลื่อนไหวเด่นของสัปดาห์, HOOK ที่แกะมาได้ |
| เทรนด์วันนี้ | ข่าวจาก 12 sources ติด tag HOOK/EXPLAIN/SKIP + Claude แนะนำ |
| คลัง HOOK | 482 hooks **ค้นหาได้จริง** (พิมพ์ในช่องค้นหา) |
| ตั้งเวลาโพสต์ | เลือกแพลตฟอร์ม → เวลาโพสต์ → caption รายแพลตฟอร์ม (กดสลับได้) |
| ปฏิทิน CONTENT | ปฏิทินเดือน มิ.ย. 2026 — **กดวันที่มีคิวเพื่อดู script เต็ม** |
| ADS · FB/IG | งบ/ลูกค้า/ROAS + ตารางผลงานแต่ละ Campaign + Claude แนะนำ |

## ที่ต้องแก้ก่อนใช้จริง

ตอนนี้เป็น **ตัวอย่างระบบ (demo)** — ตัวเลขทั้งหมดเป็นข้อมูลสมมติที่ฝังไว้ในไฟล์
ถ้าจะใช้กับธุรกิจจริง ต้องต่อของจริงเพิ่ม 3 อย่าง:

1. **Connectors** — ต่อ Instagram Graph API / Facebook / TikTok / YouTube / Meta Ads
   เพื่อดึงยอดวิว ยอดขาย และตัวเลขโฆษณาเข้ามาแทนข้อมูลตัวอย่าง
2. **Always-On** — ตั้ง cron / scheduled job ให้ยิงทุกวัน 6:00 น. แล้วให้ Claude
   สรุปผลลงหน้า "ภาพรวม" (ตอนนี้ข้อความสรุปเป็นตัวอย่างที่เขียนไว้ล่วงหน้า)
3. **ที่เก็บข้อมูล** — ฐานข้อมูลหรือ Google Sheets สำหรับเก็บ hooks / ปฏิทิน / ประวัติตัวเลข
   (ตอนนี้ข้อมูลอยู่ในไฟล์ ไม่ได้บันทึกเมื่อรีเฟรช)

โครงหน้าตาและการทำงานฝั่งหน้าจอครบแล้ว — เหลือแค่เปลี่ยนแหล่งข้อมูล

## แก้ข้อมูลตัวอย่าง

ทุกอย่างอยู่ใน `index.html` ไฟล์เดียว:

- ตัวเลข KPI / ตาราง / รายการต่าง ๆ — แก้ตรง HTML ของหน้านั้น ๆ ได้เลย
- คำอธิบายกล่อง CORE (ปุ่ม `?`) — ตัวแปร `INFO` ใน `<script>`
- คิวในปฏิทินและ script เต็ม — ตัวแปร `EVENTS` และ `SCRIPTS` ใน `<script>`
- สี / ฟอนต์ — ตัวแปร CSS ใน `:root` ด้านบนสุดของไฟล์
