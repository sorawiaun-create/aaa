# Content OS — Marketing System

ระบบตามที่เห็นในวิดีโอ: หน้า **แผนผังระบบ (Marketing System)** ที่กดเข้าไปดูได้ทุกกล่อง
พร้อมหน้าย่อยครบทั้ง 9 หน้า

หน้าเว็บ **render จากข้อมูล** ไม่ได้ hardcode — เปิดเปล่า ๆ จะใช้ข้อมูลตัวอย่าง
ถ้ามี `data.json` จะใช้ข้อมูลจริงแทน

`data.json` สร้างวันละครั้งตอน 6 โมงเช้า โดย:
1. **ดึงตัวเลขจริง** จาก Meta Ads + Instagram
2. **ให้ Claude ค้นเว็บเอง** ว่าวงการนี้มีเทรนด์อะไร ใครกำลังมาแรง
3. **ให้ Claude วางแผนคอนเทนต์ทั้งชุด** — คลัง HOOK · ปฏิทิน + สคริปต์เต็ม · สรุปเช้านี้ · สิ่งที่ควรทำวันนี้

เจ้าของธุรกิจไม่ต้องกรอกอะไรเลย — Claude อ่าน bio กับแคปชันล่าสุดของบัญชี IG
แล้วเดาเองว่าธุรกิจนี้ทำอะไร ลูกค้าเป็นใคร โทนแบบไหน

## วิธีเปิด

**แบบเร็วสุด** — ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง ไม่ต้อง build
(เหมือนในวิดีโอที่เปิดจาก `file://`) จะแชร์ให้คนอื่นก็ส่งไฟล์นี้ไฟล์เดียว

**แบบเห็นข้อมูลจริง** — ต้องเปิดผ่าน http เพราะเบราว์เซอร์ห้าม `file://` อ่านไฟล์ข้างเคียง:

```bash
cd content-os && python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

แถบด้านบนของหน้าแผนผังจะบอกเองว่ากำลังใช้ **ตัวอย่างระบบ** หรือ **ข้อมูลจริง**

## โครงสร้างระบบ

```
CORE · สมองของระบบ            ← กดปุ่ม ? ที่มุมการ์ดเพื่อดูคำอธิบาย
├── Claude          — สั่งงานทุกอย่างผ่านตัวเดียว
├── Context Memory  — จำธุรกิจ/โทน/ลูกค้าของคุณได้
├── Always-On       — ตื่นทำงานเองทุกเช้า 6:00
└── Connectors      — ต่อ IG · FB · TikTok · YouTube · Meta Ads · Sheets

Data วิเคราะห์ผล        ทำคอนเทนต์            โฆษณา
├── ANALYTICS          ├── คลัง HOOK         └── ADS · FB/IG
├── ติดตามคู่แข่ง       ├── ปฏิทิน CONTENT         (CAMPAIGN ไหนคุ้ม)
└── เทรนด์วันนี้         └── ตั้งเวลาโพสต์

OUTPUT · สิ่งที่คุณเห็นทุกเช้า
└── ภาพรวม + รายงานสรุปทุกเช้า
```

## หน้าที่มีทั้งหมด

| หน้า | มีอะไร | ข้อมูลจริง |
| --- | --- | --- |
| แผนผังระบบ | ไดอะแกรมทั้งระบบ กดกล่องไหนก็เข้าไปดูข้างในได้ | — |
| ภาพรวม | KPI + สรุปเช้านี้โดย Claude + สิ่งที่ควรทำวันนี้ | ✅ IG + Meta Ads |
| ANALYTICS | Views / Reach / Profile พร้อมกราฟ + โพสต์ที่แรงที่สุด | ✅ Instagram |
| ติดตามคู่แข่ง | creators, ความเคลื่อนไหวเด่น, HOOK ที่แกะมาได้ | ✦ Claude ค้นเว็บ |
| เทรนด์วันนี้ | ข่าวติด tag HOOK/EXPLAIN/SKIP + Claude แนะนำ | ✦ Claude ค้นเว็บ |
| คลัง HOOK | hooks **ค้นหาได้จริง** (พิมพ์ในช่องค้นหา) | ✦ Claude เขียน |
| ตั้งเวลาโพสต์ | เลือกแพลตฟอร์ม → เวลาโพสต์ → caption รายแพลตฟอร์ม | ตัวอย่าง |
| ปฏิทิน CONTENT | ปฏิทินรายเดือน — **กดวันที่มีคิวเพื่อดู script เต็ม** | ✦ Claude วางแผน |
| ADS · FB/IG | งบ/ลูกค้า/ROAS + ตารางแต่ละ Campaign + Claude แนะนำ | ✅ Meta Ads |

## ต่อข้อมูลจริง

### 1. เตรียม token

ต้องมี Meta access token (System User token แนะนำ เพราะไม่หมดอายุง่าย)
สิทธิ์ที่ต้องมี: `ads_read`, `instagram_basic`, `instagram_manage_insights`, `pages_read_engagement`

ถ้า repo นี้ตั้ง `FB_ACCESS_TOKEN` ไว้แล้วสำหรับ Facebook Ads Automation — **ใช้ตัวเดียวกันได้เลย**

### 2. รันเองในเครื่อง

```bash
pip install -r content-os/requirements.txt
cp content-os/.env.example content-os/.env    # ใส่ค่าจริง
export $(grep -v '^#' content-os/.env | xargs)
python content-os/scripts/build_data.py       # -> content-os/data.json
```

### 3. ให้รันเองทุกเช้า

`.github/workflows/content-os-daily.yml` ตั้งไว้แล้ว — ยิงทุกวัน **6:00 น. เวลาไทย**
แล้ว commit `content-os/data.json` กลับเข้า repo (รูปแบบเดียวกับ `status.json` ของ Ads Automation)

ใส่ค่าที่ **Settings → Secrets and variables → Actions**:

| Secret | จำเป็น | ถ้าไม่ใส่ |
| --- | --- | --- |
| `FB_ACCESS_TOKEN` | ✅ | ข้ามทั้งหมด ใช้ข้อมูลตัวอย่าง |
| `FB_AD_ACCOUNT_ID` | ถ้าอยากได้หน้า ADS | หน้า ADS ใช้ข้อมูลตัวอย่าง |
| `IG_USER_ID` | ถ้าอยากได้หน้า ANALYTICS | หน้า ANALYTICS ใช้ข้อมูลตัวอย่าง |
| `ANTHROPIC_API_KEY` | ถ้าอยากให้ AI คิดคอนเทนต์เอง | ได้แค่ตัวเลขจริง ส่วนที่ต้องคิดใช้ข้อมูลตัวอย่าง |

ใส่แค่บางตัวก็ได้ — ส่วนที่ต่อไม่ได้จะใช้ข้อมูลตัวอย่างต่อไป และขึ้นเตือนบนแถบด้านบน
กดรันทันทีได้ที่แท็บ **Actions → Content OS — รายงานเช้า → Run workflow**

## AI คิดให้ยังไง

`scripts/brain.py` เรียก Claude 2 รอบต่อวัน:

| รอบ | ทำอะไร | ได้อะไรกลับมา |
| --- | --- | --- |
| `research` | ค้นเว็บ (server-side web search) จาก bio + แคปชันของบัญชี | บันทึกเทรนด์ 7 วันล่าสุด + ครีเอเตอร์สายเดียวกันที่มาแรง |
| `plan` | เอาตัวเลขจริง + ผลค้น มาวางแผน (structured output ตาม `PLAN_SCHEMA`) | เทรนด์ · คู่แข่ง · คลัง HOOK · ปฏิทิน + สคริปต์เต็ม · สรุป · สิ่งที่ควรทำ |

กติกาที่ใส่ไว้ใน prompt: **ห้ามแต่งตัวเลข** ถ้าไม่มีข้อมูลให้พูดเชิงคุณภาพแทน
และครีเอเตอร์/เทรนด์ต้องมาจากผลค้นเว็บจริงเท่านั้น ห้ามแต่งชื่อบัญชีขึ้นเอง

ถ้าขั้น AI ล้มเหลว (คีย์หมดอายุ เน็ตล่ม โมเดลปฏิเสธ) **ตัวเลขจริงยังถูกเขียนลงไฟล์ตามปกติ**
ส่วนที่ AI คิดจะกลับไปใช้ข้อมูลตัวอย่าง และขึ้นเตือนบนแถบด้านบน

### ค่าใช้จ่าย

รันวันละครั้งด้วย `claude-opus-5` ($5 / 1M token ขาเข้า, $25 / 1M ขาออก)
ประมาณ **฿10–20 ต่อวัน** ขึ้นกับว่าค้นเว็บมากแค่ไหน — ค่าเครื่องมือค้นเว็บคิดแยกจาก token

อยากประหยัดกว่านี้ตั้ง `CONTENT_OS_MODEL=claude-sonnet-5` ได้ (ถูกกว่าราว 2.5 เท่า)

### ส่วนที่ยังต้องทำเอง

**ตั้งเวลาโพสต์** ยังเป็นข้อมูลตัวอย่าง — การโพสต์จริงต้องขอสิทธิ์
`instagram_content_publish` และผ่าน App Review ของ Meta ก่อน ซึ่งใช้เวลาอนุมัติ

## แก้ข้อมูล / ปรับหน้าตา

ทุกอย่างอยู่ใน `index.html` ไฟล์เดียว:

| อยากแก้ | ดูที่ |
| --- | --- |
| ข้อมูลตัวอย่างทั้งหมด | ตัวแปร `DEMO` ใน `<script>` |
| คำอธิบายกล่อง CORE (ปุ่ม `?`) | `DEMO.core` |
| คิวปฏิทิน + script เต็ม | `DEMO.calendar.days` |
| สี / ฟอนต์ | ตัวแปร CSS ใน `:root` บนสุดของไฟล์ |

`data.json` ใช้โครงเดียวกับ `DEMO` เป๊ะ ๆ — key ไหนที่มีใน `data.json` จะทับของเดิม
key ไหนไม่มีก็ใช้ข้อมูลตัวอย่างต่อไป

> ข้อความในฟิลด์ `summary` และ `advice` ใส่ `<b>` `<i>` ได้ (ไว้เน้นคำ) — tag อื่นถูกตัดทิ้งทั้งหมด
