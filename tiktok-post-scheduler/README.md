# TikTok Clip Scheduler (ปักตะกร้า) — Chrome Extension

ตั้งเวลา **ทยอยโพสต์คลิปของช่องตัวเอง** พร้อม **ปักตะกร้าสินค้า** โดยฝังในหน้า `tiktok.com`
ใช้ session ที่คุณล็อกอินอยู่ — แนวเดียวกับ GMV Max Controller ที่คุณใช้อยู่

เหมาะกับกรณี: มีคลิปสินค้าเยอะ พนักงานโพสต์ไม่ทัน อยากให้ระบบช่วยจัดคิวและทยอยลงตามเวลา

---

## ⚠️ อ่านก่อนใช้ (สำคัญ)

- วิธีนี้ทำงาน **นอก API ทางการของ TikTok** → มีความเสี่ยงเรื่องข้อกำหนดการใช้งาน (ToS)
  และการถูกจำกัด/ระงับบัญชี — **ความเสี่ยงตกที่บัญชีของคุณเอง**
- ใช้กับ **ช่องของตัวเอง + คอนเทนต์ของตัวเอง** เท่านั้น
- **ทยอยลงในอัตราธรรมชาติ** อย่ายิงถี่เกิน (ตั้ง "เว้นขั้นต่ำ" + "โพสต์/วัน" ให้สมเหตุสมผล)
- บัญชีต้องมีสิทธิ์ **TikTok Shop / Affiliate** อยู่แล้ว ถึงจะปักตะกร้าได้
- **ทดสอบด้วยโหมด dry-run กับคลิปเดียวก่อนเสมอ** แล้วค่อยเปิดใช้จริง

---

## ติดตั้ง (Load unpacked)

1. เปิด Chrome → พิมพ์ `chrome://extensions` → กด Enter
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** → เลือกโฟลเดอร์ `tiktok-post-scheduler` นี้ (ทั้งโฟลเดอร์)
4. ปักหมุด extension ไว้บนแถบ Chrome → คลิกไอคอนเพื่อเปิด **Side Panel**
5. เปิดหน้า `https://www.tiktok.com/tiktokstudio/upload` และล็อกอินให้เรียบร้อย

## วิธีใช้

**ข้อ 1 — เพิ่มคลิปเข้าคิว**
เลือกไฟล์วิดีโอ (เลือกทีละหลายไฟล์ได้), ใส่แคปชั่น/แฮชแท็ก/คำค้นสินค้า → กด "เพิ่มเข้าคิว"
ไฟล์ถูกเก็บใน IndexedDB ของเบราว์เซอร์ (รองรับหลายร้อยไฟล์ ด้วย `unlimitedStorage`)

**ข้อ 2 — กระจายเวลาโพสต์**
ตั้งเวลาเริ่ม, โพสต์/วัน, ช่วงชั่วโมงที่โพสต์, เว้นขั้นต่ำ, สุ่มบวก → กด "จัดตาราง"
ระบบจะกระจายคลิปทั้งคิวออกเป็นหลายวันแบบทยอย (ไม่ยิงรวด) — เห็นเวลาของแต่ละคลิปในรายการ

**ข้อ 3 — โหมดการทำงาน**
- *เปิดตัวตั้งเวลา* — ให้ระบบทยอยโพสต์เองตามตาราง
- *โพสต์อัตโนมัติ* — เปิด = กดปุ่มโพสต์ให้ / ปิด = เติมข้อมูลครบแล้วหยุดรอคุณกดเอง (แนะนำช่วงแรก)
- *Dry-run* — เดินทุกขั้นแต่ไม่พิมพ์/ไม่กดจริง (ไว้ลองว่า selector ตรงหน้าจริงไหม)
- ปุ่ม "ลองโพสต์ตัวถัดไปเดี๋ยวนี้" — ทดสอบทันทีโดยไม่รอถึงเวลา

**ลำดับที่แนะนำครั้งแรก:** เพิ่ม 1 คลิป → เปิด Dry-run → กด "ลองโพสต์ตัวถัดไป" →
ดูใน console ของหน้า TikTok ว่าเดินถึงขั้นไหน → ถ้าโอเค ค่อยปิด dry-run แล้วทดสอบโพสต์จริง 1 ตัว

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `manifest.json` | ตั้งค่า Extension (MV3) + สิทธิ์ |
| `schedule.js` | ตรรกะกระจายเวลาโพสต์ (บริสุทธิ์ — มี unit test) |
| `db.js` | เก็บคลิป/คิว ลง IndexedDB |
| `background.js` | ตัวตั้งเวลา (alarms) → สั่งโพสต์ทีละคลิป |
| `content-upload.js` | ขับ DOM หน้าอัปโหลด: ใส่ไฟล์ → แคปชั่น → ปักตะกร้า → กดโพสต์ |
| `panel.html` / `panel.js` | หน้า Side Panel จัดการคิว/ตาราง/โหมด |
| `tests/schedule.test.mjs` | ทดสอบตรรกะเวลา (`node --test`) |

รันเทสต์: `node --test` (ในโฟลเดอร์นี้)

## เรื่อง selector หน้า TikTok (ต้องรู้)

`content-upload.js` ขับหน้าอัปโหลดด้วย selector + การจับปุ่มจากข้อความ (ไทย/อังกฤษ)
**TikTok เปลี่ยนหน้าเว็บบ่อย** — ถ้าวันไหนอัตโนมัติไม่ตรง ให้:

1. เปิด Dry-run แล้วดู log ใน DevTools Console ของหน้า TikTok ว่าค้างขั้นไหน
2. ขั้นที่มักต้องปรับคือ **ปุ่มเพิ่มสินค้า/ปักตะกร้า** และ **ปุ่มโพสต์** (ข้อความบนปุ่มอาจเปลี่ยน)
3. แก้รายการคำในฟังก์ชัน `findByText(...)` และ selector ช่องแคปชั่น/ช่องค้นหาให้ตรงหน้าจริง
4. มีฟังก์ชัน `inspectCandidates()` (ส่งข้อความ `INSPECT`) ไว้ช่วยดู element ที่เจอในหน้า

> ส่วน "จัดคิว + ตั้งเวลา + เก็บไฟล์ + กระจายเวลา" ทำงานครบและเทสต์แล้ว
> ส่วนที่ต้องจูนกับหน้าจริงคือ **ขั้นตอนขับ DOM ตอนโพสต์** เท่านั้น
