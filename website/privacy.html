นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด: 29 กรกฎาคม 2569 (2026)

Chobtham ("เรา") ให้ความสำคัญกับความเป็นส่วนตัวของผู้ใช้บริการและลูกค้าของเรา นโยบายฉบับนี้อธิบายว่าเราเก็บรวบรวม ใช้ เปิดเผย และปกป้องข้อมูลอย่างไร เมื่อคุณใช้งานเว็บไซต์และบริการของเรา

1. ข้อมูลที่เราเก็บรวบรวม

  • ข้อมูลติดต่อ เช่น ชื่อ อีเมล เบอร์โทรศัพท์ ที่คุณให้ไว้เมื่อติดต่อหรือสมัครใช้บริการ
  • ข้อมูลบัญชีโฆษณา เมื่อคุณอนุญาตให้เราบริหารจัดการโฆษณาแทน เราอาจเข้าถึงข้อมูลแคมเปญและสถิติผ่าน API ของแพลตฟอร์มโฆษณา (เช่น TikTok, Meta, Google) เท่าที่จำเป็นต่อการให้บริการ
  • ข้อมูลการใช้งานเว็บไซต์ เช่น ประเภทอุปกรณ์ เบราว์เซอร์ และข้อมูลที่เก็บผ่านคุกกี้เพื่อพัฒนาประสบการณ์การใช้งาน

2. วิธีที่เราใช้ข้อมูล

  • เพื่อให้บริการที่ปรึกษาและบริหารโฆษณาตามที่ตกลงกับคุณ
  • เพื่อวิเคราะห์ประสิทธิภาพแคมเปญและจัดทำรายงาน
  • เพื่อติดต่อสื่อสาร ตอบคำถาม และให้การสนับสนุน
  • เพื่อปฏิบัติตามข้อกำหนดทางกฎหมายและนโยบายของแพลตฟอร์มที่เกี่ยวข้อง

3. การเข้าถึงข้อมูลผ่าน TikTok และแพลตฟอร์มโฆษณา

เมื่อคุณเชื่อมต่อบัญชีโฆษณากับบริการของเรา เราจะเข้าถึงและประมวลผลข้อมูลผ่าน API อย่างเป็นทางการของแพลตฟอร์มนั้น ๆ โดยใช้เพื่อการบริหารและเพิ่มประสิทธิภาพแคมเปญของคุณเท่านั้น เราไม่ขายหรือนำข้อมูลของคุณไปใช้นอกเหนือจากวัตถุประสงค์ที่ระบุไว้ และคุณสามารถยกเลิกการอนุญาต (revoke) ได้ทุกเมื่อผ่านการตั้งค่าบัญชีของแพลตฟอร์ม

4. การเปิดเผยข้อมูลต่อบุคคลที่สาม

เราจะไม่ขายข้อมูลส่วนบุคคลของคุณ เราอาจเปิดเผยข้อมูลเฉพาะกับผู้ให้บริการที่จำเป็นต่อการดำเนินงาน (เช่น ผู้ให้บริการโครงสร้างพื้นฐานหรือเครื่องมือวิเคราะห์) ภายใต้ข้อตกลงการรักษาความลับ หรือเมื่อกฎหมายกำหนด

5. การเก็บรักษาและความปลอดภัย

เราจัดเก็บข้อมูลไว้เท่าที่จำเป็นต่อการให้บริการและตามที่กฎหมายกำหนด พร้อมใช้มาตรการทางเทคนิคและการบริหารจัดการที่เหมาะสมเพื่อปกป้องข้อมูลจากการเข้าถึงโดยไม่ได้รับอนุญาต

6. สิทธิของคุณ

คุณมีสิทธิขอเข้าถึง แก้ไข ลบ หรือขอให้ระงับการใช้ข้อมูลส่วนบุคคลของคุณ รวมถึงถอนความยินยอมได้ โดยติดต่อเราตามช่องทางด้านล่าง

7. คุกกี้

เว็บไซต์ของเราอาจใช้คุกกี้เพื่อการทำงานพื้นฐานและการวิเคราะห์การใช้งาน คุณสามารถตั้งค่าเบราว์เซอร์เพื่อปฏิเสธคุกกี้ได้ แต่บางฟังก์ชันอาจทำงานไม่สมบูรณ์

8. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้เป็นครั้งคราว โดยจะระบุวันที่ปรับปรุงล่าสุดไว้ด้านบนของหน้า

9. ติดต่อเรา
