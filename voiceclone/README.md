# 🎙️ VoiceClone AI

**แปลงข้อความเป็นเสียงพูดด้วยเสียงของคุณเอง — ทำงานบนเครื่องของคุณ 100%**

อัปโหลดเสียงตัวอย่างสั้น ๆ → พิมพ์ข้อความ → กดสร้าง → ดาวน์โหลดไฟล์เสียงไปใช้ได้ทันที
ข้อมูลทั้งหมดประมวลผลในเครื่อง ไม่มีการส่งเสียงของคุณขึ้นเซิร์ฟเวอร์ภายนอก

เหมาะสำหรับ: 🎬 ทำคลิปวิดีโอ · 🎧 เสียงบรรยาย · 📱 คอนเทนต์ TikTok / YouTube / Reels · 📢 งานโฆษณา / รีวิวสินค้า

## ⚙️ เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|------|-----------|
| โมเดลโคลนเสียง | **F5‑TTS** + เช็คพอยต์ภาษาไทย [`VIZINTZOR/F5-TTS-THAI`](https://huggingface.co/VIZINTZOR/F5-TTS-THAI) |
| ปรับข้อความไทย | `pythainlp` (ไม่บังคับ แต่ช่วยให้ออกเสียงดีขึ้น) |
| เว็บเซิร์ฟเวอร์ | FastAPI + Uvicorn |
| หน้าเว็บ | HTML / CSS / JavaScript ล้วน (ไม่ต้อง build) |

โมเดลจะถูกดาวน์โหลดอัตโนมัติจาก Hugging Face ในการใช้งานครั้งแรก (ประมาณ ~1.3 GB)
และเก็บไว้ในเครื่องเพื่อใช้ครั้งต่อไป

## 📋 ความต้องการของระบบ

- **Python 3.10 – 3.11**
- **FFmpeg (แบบ shared ที่มีไฟล์ DLL)** — จำเป็นสำหรับอ่านไฟล์เสียง
  - Windows: `winget install --id "Gyan.FFmpeg.Shared"`
  - macOS: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg`
  - หลังติดตั้งบน Windows ให้เปิดหน้าต่าง cmd ใหม่ เพื่อให้ระบบเห็น FFmpeg
- RAM อย่างน้อย 8 GB (แนะนำ 16 GB)
- พื้นที่ว่างประมาณ 5 GB สำหรับไลบรารีและโมเดล
- ⚠️ **วางโปรเจกต์ไว้ในโฟลเดอร์ที่ที่อยู่สั้น ๆ** เช่น `C:\vc` (Windows มีข้อจำกัดความยาว path ~260 ตัวอักษร)
- (ไม่บังคับ) การ์ดจอ NVIDIA + CUDA จะเร็วขึ้นมาก — ถ้าไม่มีจะรันบน CPU ได้ แต่ช้ากว่า

## 🚀 วิธีติดตั้งและใช้งาน

### วิธีที่ง่ายที่สุด (สคริปต์สำเร็จรูป)

**macOS / Linux**
```bash
cd voiceclone
./run.sh
```

**Windows** — ดับเบิลคลิก `run.bat` หรือรันในคอมมานด์พรอมต์
```bat
cd voiceclone
run.bat
```

สคริปต์จะสร้าง virtual environment, ติดตั้ง dependency และเปิดเซิร์ฟเวอร์ให้เอง

### วิธีติดตั้งเอง (manual)

```bash
cd voiceclone
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ 👉 **http://127.0.0.1:8000**

## 🖱️ ขั้นตอนการใช้งาน

1. **อัปโหลดเสียงตัวอย่าง** — ไฟล์ WAV / MP3 / FLAC / OGG / M4A ความยาว ~5–12 วินาที
   (เสียงชัด พูดต่อเนื่อง ไม่มีเสียงดนตรี/เสียงรบกวน จะได้ผลดีที่สุด)
2. **(แนะนำ) พิมพ์ข้อความที่พูดในไฟล์ตัวอย่าง** ให้ตรงกับเสียง จะโคลนได้เหมือนขึ้นมาก
   ถ้าเว้นว่างไว้ ระบบจะถอดเสียงให้อัตโนมัติ (ช้ากว่า)
3. **พิมพ์ข้อความภาษาไทย** ที่ต้องการให้พูด
4. **(ไม่บังคับ) เลือกโทนเสียง** เช่น แม่ค้า/ขายของ, รีวิว/ป้ายยา, ท่องเที่ยว, ทางการ
   — พรีเซ็ตนี้ปรับจังหวะการพูดให้เข้ากับสไตล์ (โทนหลักยังมาจากไฟล์เสียงตัวอย่าง)
5. **(ไม่บังคับ) เลือกความเร็วการสร้าง** — เร็วสุด / สมดุล / คุณภาพสูงสุด
6. **กดปุ่ม "สร้างเสียงพูด"** — รอสักครู่ (ครั้งแรกจะนานเพราะต้องโหลดโมเดล)
7. **ฟังตัวอย่างและดาวน์โหลด** ไฟล์ `.wav` ไปใช้งานได้เลย

## 🇹🇭 เกี่ยวกับภาษาไทย

โปรแกรมนี้ใช้เช็คพอยต์ [`VIZINTZOR/F5-TTS-THAI`](https://huggingface.co/VIZINTZOR/F5-TTS-THAI)
ที่เทรนมาสำหรับภาษาไทยโดยเฉพาะ จึงพูดไทยได้เป็นธรรมชาติและโคลนเสียงได้ในตัวเดียว

เคล็ดลับให้ได้เสียงดีที่สุด:
- ใช้ตัวอย่างเสียงที่ **ชัด ไม่มีเสียงรบกวน** ยาวประมาณ 5–12 วินาที
- **กรอกข้อความที่พูดในไฟล์ตัวอย่างให้ตรง** จะช่วยเรื่องความเหมือนอย่างมาก
- ประโยคสั้น–กลางจะเป็นธรรมชาติกว่าประโยคยาวมาก ๆ
- **คุมจังหวะหยุดเอง:** กด Enter ขึ้นบรรทัดใหม่ตรงไหน = เว้นจังหวะหยุดตรงนั้น
  แต่ละบรรทัดจะถูกสร้างแยกกันแล้วต่อเสียงเข้าด้วยกัน ช่วยให้เสียงไม่เพี้ยนเมื่อข้อความยาว
  (F5-TTS จะเริ่มเพี้ยนถ้าสร้างยาวเกิน ~10 วินาทีในครั้งเดียว)

**ตัวเลขและคำอังกฤษ:** ระบบจะแปลงเป็นคำอ่านไทยให้อัตโนมัติ (เช่น `123` → "หนึ่งร้อยยี่สิบสาม",
`TikTok` → "ติ๊กต็อก") — คำอังกฤษที่ไม่รู้จักจะสะกดทีละตัวอักษร ถ้าอยากให้อ่านแบบไหนเป๊ะ ๆ
แนะนำให้พิมพ์เป็นคำไทยไปเลย (เช่นพิมพ์ "ไอโฟน" แทน "iPhone")

> โครงสร้างโค้ดออกแบบให้เปลี่ยนเช็คพอยต์ได้ง่ายในไฟล์ `tts_engine.py`
> (แก้ตัวแปร `HF_REPO`) หากในอนาคตมีโมเดลไทยรุ่นใหม่ที่ดีกว่า

## 📁 โครงสร้างโปรเจกต์

```
voiceclone/
├── app.py              # FastAPI backend + REST API
├── tts_engine.py       # ตัวห่อโมเดล F5‑TTS ภาษาไทย (โหลดแบบ lazy)
├── requirements.txt
├── run.sh / run.bat    # สคริปต์เปิดใช้งาน
├── static/
│   ├── index.html      # หน้าเว็บ
│   ├── style.css
│   └── app.js
├── samples/            # เสียงตัวอย่างที่อัปโหลด (ลบทิ้งหลังใช้)
└── outputs/            # ไฟล์เสียงที่สร้าง (.wav)
```

### API endpoints

| Method | Path | หน้าที่ |
|--------|------|--------|
| `POST` | `/api/generate`  | รับ `sample` (ไฟล์), `text`, `ref_text` (ไม่บังคับ) → สร้างเสียง |
| `GET`  | `/api/audio/{id}` | ดึงไฟล์เสียงที่สร้าง (ใส่ `?download=1` เพื่อดาวน์โหลด) |

## 🔧 แก้ปัญหาที่พบบ่อย

- **`Could not load libtorchcodec ... coreN.dll`** — PyTorch เวอร์ชันใหม่เกินไปจนไม่เข้ากับ torchcodec
  แก้ด้วยการล็อกเวอร์ชันแล้วถอน torchcodec (ทำในโฟลเดอร์โปรเจกต์ ตอน venv เปิดอยู่):
  ```
  pip install torch==2.6.0 torchaudio==2.6.0
  pip uninstall -y torchcodec
  ```
  (`requirements.txt` ล็อกเวอร์ชันนี้ไว้แล้ว การติดตั้งใหม่ตั้งแต่ต้นจะไม่เจอปัญหานี้)
- **`No such file or directory ... predicated_tile_access...` ตอน pip install** — path ยาวเกินไป
  ให้ย้ายโปรเจกต์ไปไว้ที่ `C:\vc` แล้วติดตั้งใหม่
- **ครั้งแรกช้ามาก** — เป็นเรื่องปกติ ระบบกำลังดาวน์โหลดโมเดล ครั้งต่อไปจะเร็วขึ้น
- **ติดตั้ง `f5-tts` ไม่ผ่าน** — ตรวจสอบว่าใช้ Python 3.10–3.11 (เวอร์ชันใหม่เกินไปอาจยังไม่รองรับ)
- **เสียงออกมาไม่เหมือน** — กรอก "ข้อความที่พูดในไฟล์ตัวอย่าง" ให้ตรง และใช้ไฟล์ที่ชัด ไม่มีเสียงรบกวน
- **รันบน CPU ช้า** — F5‑TTS จะเร็วขึ้นมากถ้ามีการ์ดจอ NVIDIA (CUDA) แต่ใช้ CPU ก็ได้ เพียงแต่ต้องรอนานกว่า
