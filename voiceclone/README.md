# 🎙️ VoiceClone AI

**แปลงข้อความเป็นเสียงพูดด้วยเสียงของคุณเอง — ทำงานบนเครื่องของคุณ 100%**

อัปโหลดเสียงตัวอย่างสั้น ๆ → พิมพ์ข้อความ → กดสร้าง → ดาวน์โหลดไฟล์เสียงไปใช้ได้ทันที
ข้อมูลทั้งหมดประมวลผลในเครื่อง ไม่มีการส่งเสียงของคุณขึ้นเซิร์ฟเวอร์ภายนอก

## ⚙️ เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|------|-----------|
| โมเดลโคลนเสียง | **XTTS‑v2** (zero‑shot voice cloning) ผ่านไลบรารี `coqui-tts` |
| เว็บเซิร์ฟเวอร์ | FastAPI + Uvicorn |
| หน้าเว็บ | HTML / CSS / JavaScript ล้วน (ไม่ต้อง build) |

โมเดลจะถูกดาวน์โหลดอัตโนมัติในการใช้งานครั้งแรก (ประมาณ ~1.8 GB) และเก็บไว้ในเครื่องเพื่อใช้ครั้งต่อไป

---

## 📋 ความต้องการของระบบ

- **Python 3.9 – 3.11**
- RAM อย่างน้อย 8 GB (แนะนำ 16 GB)
- พื้นที่ว่างประมาณ 3 GB สำหรับโมเดล
- (ไม่บังคับ) การ์ดจอ NVIDIA + CUDA จะเร็วขึ้นมาก — ถ้าไม่มีจะรันบน CPU ได้ แต่ช้ากว่า

## 🚀 วิธีติดตั้งและใช้งาน

### วิธีที่ง่ายที่สุด (สคริปต์สำเร็จรูป)

**macOS / Linux**
```bash
cd voiceclone
./run.sh
```

**Windows** — ดับเบิลคลิก `run.bat` หรือรันในคอมมานด์พรอมต์
```bat
cd voiceclone
run.bat
```

สคริปต์จะสร้าง virtual environment, ติดตั้ง dependency และเปิดเซิร์ฟเวอร์ให้เอง

### วิธีติดตั้งเอง (manual)

```bash
cd voiceclone
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ 👉 **http://127.0.0.1:8000**

## 🖱️ ขั้นตอนการใช้งาน

1. **อัปโหลดเสียงตัวอย่าง** — ไฟล์ WAV / MP3 / FLAC / OGG / M4A ความยาว ~6–20 วินาที
   (เสียงชัด พูดต่อเนื่อง ไม่มีเสียงดนตรี/เสียงรบกวน จะได้ผลดีที่สุด)
2. **พิมพ์ข้อความ** ที่ต้องการให้พูด และเลือกภาษา
3. **กดปุ่ม "สร้างเสียงพูด"** — รอสักครู่ (ครั้งแรกจะนานหน่อยเพราะต้องโหลดโมเดล)
4. **ฟังตัวอย่างและดาวน์โหลด** ไฟล์ `.wav` ไปใช้งานได้เลย

อังกฤษ, สเปน, ฝรั่งเศส, เยอรมัน, อิตาลี, โปรตุเกส, โปแลนด์, ตุรกี, รัสเซีย, ดัตช์,

> ผลลัพธ์กับข้อความภาษาไทยอาจไม่แม่นยำ หากต้องการภาษาไทยโดยเฉพาะ แนะนำให้พิจารณา

## 📁 โครงสร้างโปรเจกต์

```
voiceclone/
├── app.py              # FastAPI backend + REST API
├── tts_engine.py       # ตัวห่อโมเดล XTTS‑v2 (โหลดแบบ lazy)
├── requirements.txt
├── run.sh / run.bat    # สคริปต์เปิดใช้งาน
├── static/
│   ├── index.html      # หน้าเว็บ
│   ├── style.css
│   └── app.js
├── samples/            # เสียงตัวอย่างที่อัปโหลด (ลบทิ้งหลังใช้)
└── outputs/            # ไฟล์เสียงที่สร้าง (.wav)
```

### API endpoints

| Method | Path | หน้าที่ |
|--------|------|--------|
| `GET`  | `/api/languages` | รายชื่อภาษาที่รองรับ |
| `POST` | `/api/generate`  | รับ `sample` (ไฟล์), `text`, `language` → สร้างเสียง |
| `GET`  | `/api/audio/{id}` | ดึงไฟล์เสียงที่สร้าง (ใส่ `?download=1` เพื่อดาวน์โหลด) |
