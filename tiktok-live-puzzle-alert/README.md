# 🧩 TikTok Live Puzzle Alert — แจ้งเตือนจิ๊กซอว์เข้า LINE

โปรแกรมเล็กๆ ที่คอยเฝ้าดูหน้าจอ **TikTok Live Studio** ระหว่างไลฟ์นานๆ
พอ TikTok เด้ง **กล่องจิ๊กซอว์ยืนยันตัวตน** ขึ้นมา โปรแกรมจะ:

- 📲 **ส่งแจ้งเตือนเข้า LINE** ของคุณทันที
- 🔊 เล่นเสียงเตือนดังๆ ในเครื่อง
- 🔁 ถ้ายังไม่ต่อ จะเตือนซ้ำเรื่อยๆ จนกว่าจิ๊กซอว์จะหาย

คุณจะได้รีบกลับมา **ต่อจิ๊กซอว์เอง** ทันเวลา ไม่โดนตัดไลฟ์

> ⚠️ **สำคัญ:** โปรแกรมนี้ **ไม่ได้ต่อจิ๊กซอว์ให้อัตโนมัติ** และตั้งใจออกแบบให้ไม่ทำแบบนั้น
> เพราะการหลบเลี่ยงระบบยืนยันตัวตนผิดกฎ TikTok และเสี่ยงโดนแบนบัญชี/ตัดรายได้
> โปรแกรมนี้แค่ "เตือนไม่ให้พลาดจังหวะ" — คุณยังต่อเองเหมือนเดิม จึงถูกกฎ 100%

## 🚀 วิธีใช้แบบง่ายสุด (ดับเบิลคลิก ไม่ต้องพิมพ์คำสั่ง)

โปรแกรมมี **เมนูแบบกดเลข** ให้ใช้งานง่าย มี 2 ทางเลือก:

### ทาง A — ดับเบิลคลิก `RUN.bat` (มี Python ในเครื่อง)
ดับเบิลคลิกไฟล์ **`RUN.bat`** ได้เลย ครั้งแรกมันจะติดตั้งไลบรารีให้อัตโนมัติ
แล้วเด้งเมนูขึ้นมา:

```
   1) ตั้งค่า / วาง token LINE
   2) ทดสอบส่งข้อความเข้า LINE
   3) ตั้งค่ารูปจิ๊กซอว์ (เลือกไฟล์ภาพที่แคปไว้)
   4) เริ่มเฝ้าดูหน้าจอ (รันจริง)  << ใช้ตอนไลฟ์
   5) ออก
```

กดเลขตามเมนูได้เลย ไม่ต้องพิมพ์คำสั่งอะไร 🎉

### ทาง B — สร้างไฟล์ `.exe` (ไม่ต้องมี Python เลย)
ดับเบิลคลิก **`build.bat`** หนึ่งครั้ง (ใช้เวลา 2–5 นาที) จะได้ไฟล์
**`dist\PuzzleAlert.exe`** — คัดลอกไปไว้ที่ไหนก็ได้ แล้ว **ดับเบิลคลิกเปิดใช้ได้เลย**
เครื่องอื่นที่ไม่มี Python ก็ใช้ได้ (config.json กับ templates จะถูกสร้างข้างๆ ตัว exe เอง)

> ⚙️ การ build ต้องทำบนเครื่อง **Windows** (PyInstaller สร้าง .exe สำหรับ Windows)

ก่อนใช้งานจริงยังต้องทำ **ขั้นตอนที่ 2 (สร้างบอท LINE)** และ **ขั้นตอนที่ 4 (calibrate)** ด้านล่างก่อนนะครับ
ส่วนที่เหลือ (ใส่ token / ทดสอบ / รัน) กดผ่านเมนูได้หมด

> ข้อ 1, 3, 5 ทำผ่านเมนูได้เลย เหลือแค่ต้องอ่าน **ขั้นตอนที่ 2 และ 4**

## ขั้นตอนที่ 1 — ติดตั้งโปรแกรม

เปิด Command Prompt / PowerShell แล้ว cd เข้ามาที่โฟลเดอร์นี้ จากนั้น:

```bash

.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# ติดตั้งไลบรารีที่ต้องใช้
pip install -r requirements.txt
```

## ขั้นตอนที่ 2 — สร้างบอท LINE (Messaging API) ฟรี

> LINE Notify แบบเดิมปิดบริการไปแล้ว (31 มี.ค. 2025) เราจึงใช้ **LINE Messaging API** แทน

1. เข้า https://developers.line.biz/console/ แล้วล็อกอินด้วยบัญชี LINE
2. สร้าง **Provider** ใหม่ (ตั้งชื่ออะไรก็ได้ เช่น ชื่อคุณ)
3. ใน Provider นั้น กด **Create a Messaging API channel**
   กรอกข้อมูลให้ครบ (ชื่อบอท, หมวดหมู่ ฯลฯ) แล้วสร้าง
4. เปิดแท็บ **Messaging API** ของ channel ที่เพิ่งสร้าง:
   - เลื่อนลงไปหา **Channel access token (long-lived)** กด **Issue** เพื่อสร้าง token
     แล้ว **คัดลอกเก็บไว้** (ตัวยาวๆ)
   - ตรงด้านบนจะมี **QR code ของบอท** — เอามือถือคุณสแกน **แอดบอทตัวเองเป็นเพื่อน**
     (สำคัญ! ไม่แอด = บอทส่งข้อความหาคุณไม่ได้)

> 💡 ถ้าใช้แบบ broadcast (ส่งหาทุกคนที่แอดบอท) ก็ **ไม่ต้องหา userId** ให้ยุ่งยาก
> เหมาะกับกรณีมีแค่ตัวเองแอดบอท ซึ่งเป็นค่าเริ่มต้นของโปรแกรมนี้

## ขั้นตอนที่ 3 — ตั้งค่า config

คัดลอกไฟล์ตัวอย่างเป็น `config.json`:

```bash
# Windows:
copy config.example.json config.json
# macOS/Linux:
cp config.example.json config.json
```

เปิด `config.json` แล้วใส่ **Channel access token** ที่ได้จากขั้นตอนที่ 2:

```json
{
  "line": {
    "channel_access_token": "วาง token ยาวๆ ตรงนี้",
    "to_user_id": ""
  },
  ...
}
```

> `to_user_id` เว้นว่างไว้ได้ = ใช้ broadcast ส่งหาทุกคนที่แอดบอท (รวมตัวคุณ)

### ทดสอบว่าส่ง LINE ได้ไหม

```bash
python puzzle_alert.py --test-line
```

ถ้าตั้งค่าถูก จะมีข้อความเด้งเข้า LINE ของคุณ ✅
(ถ้าไม่ได้รับ: เช็กว่า token ถูกไหม และ **แอดบอทเป็นเพื่อนแล้วหรือยัง**)

## ขั้นตอนที่ 4 — สอนโปรแกรมให้รู้จักหน้าตาจิ๊กซอว์ (calibrate)

โปรแกรมตรวจจับจิ๊กซอว์โดยการ **เทียบรูป** จึงต้องมีรูปตัวอย่างของกล่องจิ๊กซอว์ก่อน 1 ครั้ง

1. **ครั้งหน้าที่จิ๊กซอว์เด้ง** ใน TikTok Live Studio ให้กด **Print Screen**
   (หรือ `Win + Shift + S` แล้วแคปทั้งจอ) เซฟเป็นไฟล์ เช่น `shot.png` ไว้ในโฟลเดอร์นี้
2. รันคำสั่ง:

   ```bash
   python calibrate.py --image shot.png
   ```

3. จะมีหน้าต่างเด้งขึ้นให้ **ลากกรอบเลือกกล่องจิ๊กซอว์**
   - เลือกเฉพาะ **ส่วนที่อยู่นิ่งๆ** เช่น หัวข้อ/ข้อความ/ขอบกล่อง/ไอคอน
   - ❌ อย่าเลือกชิ้นจิ๊กซอว์ที่เลื่อนได้ เพราะตำแหน่งเปลี่ยนทุกครั้ง
   - ลากเสร็จกด **ENTER**
4. โปรแกรมจะบันทึกเป็น `templates/puzzle.png` ให้อัตโนมัติ
   และแนะนำค่า `region` มาให้ (จะใส่ใน config หรือไม่ก็ได้)

> ถ้ายังไม่มีภาพจิ๊กซอว์เก็บไว้ ก็รอให้มันเด้งครั้งหน้าแล้วแคปไว้ก่อน

### มีจิ๊กซอว์หลายแบบ? (เช่น แบบเลื่อนชิ้น + แบบเลือกตัวอักษร)

รองรับครับ! ทำ calibrate **ซ้ำได้เรื่อยๆ** แต่ละแบบ:
- กดเมนูข้อ 3 ใส่รูปแบบที่ 1 (เช่น แบบเลื่อนชิ้น) → บันทึกเป็น `puzzle_1.png`
- กดเมนูข้อ 3 อีกครั้ง ใส่รูปแบบที่ 2 (เช่น แบบเลือกตัวอักษร) → บันทึกเป็น `puzzle_2.png`

รูปทุกแบบจะถูกลงทะเบียนอัตโนมัติ เวลาใช้งานจริง **เจอแบบไหนก่อนก็เตือน**

> 💡 ทั้งสองแบบให้เลือกครอบ **ส่วนที่อยู่นิ่งเหมือนกันทุกครั้ง** เช่น หัวข้อ/ข้อความบอกวิธี/ขอบกล่อง
> เพราะเนื้อหาข้างใน (ชิ้นจิ๊กซอว์ หรือ ตัวอักษร) เปลี่ยนทุกครั้ง แต่กรอบ/หัวข้อเหมือนเดิม

## ขั้นตอนที่ 5 — รันจริง

ก่อนเริ่มไลฟ์ยาวๆ ให้เปิดโปรแกรมทิ้งไว้:

```bash
python puzzle_alert.py
```

จากนั้นไลฟ์ได้ตามปกติ พอจิ๊กซอว์เด้ง → LINE เด้ง + เสียงเตือนดัง → รีบไปต่อจิ๊กซอว์ 🎉
กด `Ctrl + C` เพื่อหยุดโปรแกรม

## ปรับจูนให้แม่นขึ้น

ถ้าเตือนบ่อยเกิน (false alarm) หรือ ไม่ค่อยเจอ ให้ปรับใน `config.json`:

| ค่า | ความหมาย | แนะนำ |
|-----|----------|-------|
| `threshold` | ความคล้ายขั้นต่ำที่ถือว่า "เจอ" (0–1) | เตือนมั่ว → เพิ่มเป็น 0.85–0.9 / ไม่ค่อยเจอ → ลดเป็น 0.7–0.75 |
| `region` | พื้นที่ที่สแกน `[x, y, กว้าง, สูง]` | ใส่ค่าที่ calibrate แนะนำ ช่วยให้เร็ว+แม่นขึ้น |
| `interval_seconds` | เช็กหน้าจอทุกกี่วินาที | 1–2 กำลังดี |
| `repeat_line_alert_seconds` | ส่ง LINE ซ้ำทุกกี่วินาทีถ้ายังไม่ต่อ | 30 |
| `sound_alert` | เปิด/ปิดเสียงในเครื่อง | `true` |

อยากดูว่าตอนนี้ค่าความคล้ายเท่าไหร่ ให้รันแบบ debug:

```bash
python puzzle_alert.py --debug
```

ค่า `score` ตอนจิ๊กซอว์โผล่ควรใกล้ `1.0` — ตั้ง `threshold` ให้ต่ำกว่านั้นนิดหน่อย

---

## แก้ปัญหาที่พบบ่อย

- **ไม่ได้รับ LINE** → แอดบอทเป็นเพื่อนหรือยัง / token ถูกไหม / ลอง `--test-line`
- **หน้าต่าง calibrate ไม่ขึ้น** → ต้องมีจอ/เดสก์ท็อป (รันบนเครื่องตัวเอง ไม่ใช่ผ่าน SSH)
- **จอที่ไลฟ์อยู่คนละจอกับจอหลัก** → ย้าย TikTok Live Studio มาจอหลัก หรือ ตั้ง `region` เอง
- **เตือนช้า** → ลด `interval_seconds` เหลือ 1

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|---------|
| `RUN.bat` | **ดับเบิลคลิกเพื่อเปิดเมนู** (ติดตั้งไลบรารีให้อัตโนมัติครั้งแรก) |
| `build.bat` | **ดับเบิลคลิกเพื่อสร้าง `PuzzleAlert.exe`** (ทำครั้งเดียว) |
| `app.py` | เมนูแบบกดเลข (ตัวที่ RUN.bat / .exe เรียกใช้) |
| `puzzle_alert.py` | โปรแกรมหลัก เฝ้าดูหน้าจอ + แจ้งเตือน |
| `detector.py` | ตรวจจับกล่องจิ๊กซอว์ด้วยการเทียบภาพ |
| `line_client.py` | ส่งข้อความเข้า LINE (Messaging API) |
| `sound.py` | เล่นเสียงเตือนในเครื่อง |
| `calibrate.py` | ตัวช่วยสร้างรูป template จิ๊กซอว์ |
| `config.example.json` | ไฟล์ตั้งค่าตัวอย่าง (คัดลอกเป็น `config.json`) |

> `config.json` และไฟล์รูปทั้งหมดถูกใส่ไว้ใน `.gitignore` แล้ว
> จะได้ไม่เผลอ commit token หรือรูปส่วนตัวขึ้น git
