# สถาปัตยกรรมระบบ AI ผลิตคอนเทนต์แบบหลายแผนก

ระบบนี้จำลอง "เอเจนซี่ผลิตคอนเทนต์" ทั้งทีมด้วย AI โดยแบ่งเป็นหลายแผนก
แต่ละแผนกเป็น AI agent เฉพาะทาง มี "ผู้จัดการ" (Orchestrator) คอยแตกงานและสั่งงานให้อัตโนมัติ

## แต่ละแผนกทำอะไร

| แผนก | หน้าที่ | ผลลัพธ์ที่ส่งออก |
|------|---------|-----------------|
| **วางแผนกลยุทธ์คอนเทนต์** | แปลงโจทย์เป็นแผนคอนเทนต์ | Big Idea, Content Pillars, รายการชิ้นงาน, ปฏิทิน |
| **วิจัยเทรนด์ & แฮชแท็ก** | หามุมมาแรง + แฮชแท็ก/คีย์เวิร์ด | ฟอร์แมตยอดนิยม, คีย์เวิร์ด, ชุดแฮชแท็กแยกแพลตฟอร์ม |
| **เขียนบท & แคปชั่น** | เขียน hook, สคริปต์, แคปชั่น, CTA | บทวิดีโอ, ข้อความโพสต์, แคปชั่น |
| **วิดีโอ** | สตอรี่บอร์ด + ไดเรกชันถ่าย/ตัดต่อ | Shot list, on-screen text, prompt text-to-video |
| **ภาพ & กราฟิก** | ทิศทางภาพ + prompt สร้างภาพ | mood/สไตล์, image prompts, สเปกขนาด |
| **จัดโพสต์ตามแพลตฟอร์ม** | ปรับคอนเทนต์ให้เข้ากับแต่ละแพลตฟอร์ม | โพสต์ฉบับสุดท้าย + แฮชแท็ก + เวลาโพสต์ |
| **ตรวจแบรนด์ & คุณภาพ** | ตรวจก่อนปล่อย | ✅ ผ่าน / ⚠️ แก้ก่อนปล่อย พร้อมรายการแก้ |

## กลไกการทำงาน (Orchestrator Pattern)

1. **ผู้จัดการ** ได้รับโจทย์ → ใช้โมเดล Claude คิดว่าต้องเรียกแผนกไหน ตามลำดับใด
2. ผู้จัดการเรียก **tool** `delegate_to_<แผนก>` เพื่อมอบหมายงานย่อย (Claude API tool use)
3. ระบบรัน AI agent ของแผนกนั้น (system prompt เฉพาะทาง) แล้วส่งผลกลับให้ผู้จัดการ
4. ผู้จัดการนำผลของแผนกก่อนหน้าเป็นบริบทของแผนกถัดไป (งานต่อกันเป็นสายพาน)
5. เมื่อครบทุกแผนกที่จำเป็น → ผู้จัดการรวบรวมและสรุปเป็น "แพ็กเกจคอนเทนต์พร้อมเผยแพร่"

เทคนิคเบื้องหลัง: **agentic loop + tool use** — ผู้จัดการตัดสินใจเองว่าจะเรียกแผนกไหน
ไม่ได้ hardcode ลำดับตายตัว จึงยืดหยุ่นตามโจทย์แต่ละงาน

## การต่อยอด (ทำจริงในโปรดักชัน)

- **สร้างภาพ/วิดีโอจริง**: แผนกภาพ/วิดีโอปัจจุบันส่งออกเป็น *prompt* — ต่อ API เครื่องมือ
  text-to-image / text-to-video เพื่อ render ไฟล์จริงได้ (เติมใน `runDepartment`)
- **โพสต์อัตโนมัติ**: ต่อ API ของแต่ละแพลตฟอร์ม หรือเครื่องมือตั้งเวลาโพสต์ ในแผนก "จัดโพสต์"
- **ลดต้นทุน**: เปลี่ยนบางแผนกให้ใช้โมเดลเล็กลง (เช่น Sonnet/Haiku) ผ่าน `CONFIG.departmentModel`
- **เพิ่มแผนก**: เพิ่ม object ใน `src/departments/index.js` แล้วระบบสร้าง tool ให้ผู้จัดการอัตโนมัติ
- **Human-in-the-loop**: เพิ่มขั้นให้คนอนุมัติก่อนแผนก "จัดโพสต์" ปล่อยงานจริง
